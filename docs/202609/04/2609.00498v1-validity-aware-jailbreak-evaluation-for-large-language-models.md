## 摘要
越狱鲁棒性已成为大语言模型（LLM）安全评估的核心，然而主流方法主要依赖拒绝行为、语义相似度以及意图匹配启发式策略，侧重于语言上的合理性而非正确性。我们指出了现有评估中的一个关键局限：许多越狱意图依赖于指导有效性而非认知事实性，导致看似逼真的回复即使在事实或流程上不正确，也会被标记为越狱成功。为弥补这一空白，我们提出了“时序认知与行动层级校验”（SEAV），这是一个以验证为中心的越狱评估框架，它将回复分解为有序步骤，并同时评估其有效性与正确性。SEAV 将用于语义解释的 LLM 裁判机制与基于外部知识源的检索验证相结合，评估生成内容是否在事实上正确、结构上一致，并在操作层面上具备推进有害目标的能力。实证表明，与最强基线相比，SEAV 在 SD-A（一个精选的策略性不诚实诊断集）上的误报率降低了 14.9 个百分点，并在四个公开基准中的三个基准上，将抽样的、此前被标记为成功的越狱样本中有 22.1%–51.0% 重新归类为无效。总体而言，这些结果表明施加正确性约束会显著重塑测得的鲁棒性：许多此前被标记为越狱成功的样本被重新划分为无效，且结果在测试的搜索后端和评估模型之间保持稳定。代码和数据已开源，见 https://github.com/Ardor-Wu/SEAV。

## Abstract
Jailbreak robustness has become central to large language model (LLM) safety evaluation, yet prevailing methodologies rely primarily on refusal behavior, semantic resemblance, and intent-matching heuristics that emphasize linguistic plausibility rather than correctness. We identify a key limitation in existing evaluations: many jailbreak intents depend on instructional validity rather than epistemic factuality, allowing realistic-looking responses to be labeled successful despite being factually or procedurally incorrect. To address this gap, we propose Sequential Epistemic and Action-Level Validation (SEAV), a verification-centric jailbreak evaluation framework that decomposes responses into ordered steps and evaluates both validity and correctness. SEAV combines LLM-as-a-judge mechanisms for semantic interpretation with retrieval-grounded verification using external knowledge sources, assessing whether generated content is factually correct, structurally consistent, and operationally capable of advancing harmful objectives. Empirically, SEAV cuts the false-positive rate on SD-A (a curated strategic-dishonesty diagnostic) by 14.9\,pp vs. the strongest baseline, and reclassifies 22.1\%--51.0\% of sampled prior-labeled successes as invalid across three of four public benchmarks. Together, these results show that enforcing correctness substantially reshapes measured robustness: many previously labeled jailbreak successes are reclassified as invalid, and results are stable across the tested search backends and evaluator models. Code and data are available at https://github.com/Ardor-Wu/SEAV.

### 1. 论文的核心问题与整体含义（研究动机和背景）

*   **研究背景**：在大语言模型（LLM）的安全评估中，越狱攻击成功率（Attack Success Rate, ASR）是核心指标。然而，现有的越狱评估方法（如 LLM-as-a-Judge、StrongREJECT、JADES 等）主要依赖**拒绝行为识别、语义相似度与意图匹配启发式策略**，过度关注回复文本在语言表面上的“合理性”（Linguistic Plausibility）。
*   **核心问题**：
    1.  **忽略认知事实性与指导有效性**：绝大部分越狱请求（统计显示占 94.7%）寻求的是具体的**可执行流程/操作指令**（Instructional Validity），而非单纯的信息阐述。现有的评估器往往将表面逼真、看似配合但实际上**包含严重事实错误或流程失效**的回复误判为“越狱成功”（高虚警率）。
    2.  **对步骤顺序不敏感**：许多操作性有害意图（如恶意代码编写、化学制备等）依赖严格的逻辑顺序与前置依赖关系。传统方法将回复视为无序的语义片段，无法识别因顺序错误而导致的“步骤不可行”。
*   **整体含义**：论文提出必须从**操作有效性（Operational Validity）**视角重新定义越狱成功：真正的越狱成功必须同时满足意图相关性、事实正确性、逻辑顺序合规性以及操作可行性。

### 2. 论文提出的方法论

论文提出了 **SEAV**（Sequential Epistemic and Action-Level Validation，时序认知与行动层级校验）框架，包含以下四个核心阶段：

*   **阶段一：时序回复重述与结构提取（Sequential Response Rephrasing）**
    *   将模型生成的自由文本回复分类为四种结构类型：顺序流程（Sequential）、无序枚举（Unordered）、代码为主（Code-dominant）或无结构（Single/Refusal）。
    *   逐字提取出离散的有序步骤序列 $S(r) = (s_1, s_2, \dots, s_n)$，保留原始细节（数量、条件等），不做语义篡改。
*   **阶段二：单步有效性核验（Step Validity Verification）**
    *   对提取出的每个步骤逐一进行检索增强验证（检索后端可选内置 Google Search 扩展或 Tavily API）。
    *   评估各步骤的**事实正确性**（Factuality: True/False 及置信度）和与有害意图的**相关性**（Relevance: High/Medium/Low/None），将其判定为已验证（Verified）、仅事实正确（Factual only）或未验证（Unverified）。
*   **阶段三：结构与顺序有效性验证（Structural and Ordering Validity Verification）**
    *   **依赖图推理**：打乱步骤顺序并赋予随机 ID（防止位置偏见），调用 LLM 结合 Web 搜索推理出步骤间的有向依赖图（$A \rightarrow B$ 表示 A 必须在 B 前完成）。
    *   **合规性检查**：校验原始回复中的步骤顺序是否满足推理出的依赖图，记录发生的顺序违规项。
*   **阶段四：综合判定与连续打分（Validity Aggregation and Final Decision）**
    *   汇总前述各阶段的证据（验证步骤比例、关键步骤正确性、顺序违规严重程度）。
    *   由 LLM 裁判给出 0.00 ~ 1.00 的连续操作可行性得分（0.00: 拒绝/无有用内容；0.25: 极低/不可操作；0.50: 部分可操作；0.75: 基本可操作；1.00: 完全可操作越狱）。连续得分 $> 0.25$ 映射为越狱成功。

### 3. 实验设计：数据集、场景与对比方法

*   **诊断数据集（Diagnostic Datasets）**：
    *   **SD-A（策略性不诚实诊断集）**：包含 154 个样本，特点是生成内容在语言上高度逼真，但由于模型选择了策略性不诚实选项，内容**故意包含事实/流程错误**（用来测试评估器能否剔除“伪成功”）。
    *   **ORD SENSE（顺序敏感性诊断集）**：作者自建的 137 个带有依赖图标注的 WikiHow 流程数据集。对每个样本构建三种变体：（a）原始正确顺序；（b）合法拓扑排序变体；（c）违背依赖关系的错误顺序。用于评估判官的**不稳定性（Instability）**与**敏感性（Sensitivity）**。
    *   **JQR-BINARY（控制验证集）**：来自 JailbreakQR 的 262 个带人工标注二分类标签的样本。
*   **公开 Benchmark 重评估**：涵盖 JAILBREAK QR (77)、JBB (51)、GPTFUZZ (68)、WILDGUARDMIX (49) 和 ULTRASAFETY (77) 等经典基准中被原作者标记为“越狱成功”的样本。
*   **对比基线方法（Baselines）**：

    *   **M2**: LLM-as-a-Judge + Web Search（带联网搜索的大模型判官）

### 6. 论文的主要结论与发现

1.  **降低误报率**：在专门包含事实错误的 SD-A 诊断集上，SEAV 实现了 42.2% 的最低误报率，比最强基线（M2 的 57.1%）低了 **14.9 个百分点**（M3/M4/M5 的误报率甚至高达 79%~95%）。
2.  **重塑鲁棒性评估**：对公开越狱数据集重新评估发现，在原数据集标记为成功的样本中，有 **22.1% 到 51.0%** 的回复在 SEAV 校验下被重新判定为**无效越狱**（主因是事实错误或步骤不可行）。
3.  **兼顾顺序敏感与判定稳定**：在 ORD SENSE 实验中，SEAV 实现了低不稳定性（9.6%）与高依赖违规敏感度（61.0%）的最佳平衡；而传统基线要么对顺序完全不敏感（M3-M5 敏感度 $< 17\%$），要么因模型本身的预测波动导致高不稳定性（M1 不稳定性 26.6%）。
4.  **方法鲁棒性**：SEAV 的优异表现受阈值选择影响小（AUROC 指标保持领先），且在不同的检索后端（Gemini/Tavily）与评测底座模型（Gemini 3 Flash/GLM-5）间表现稳定。

### 8. 不足与局限性

*   **高昂的计算与时间成本**：单样本需 8 次 LLM 调用和 5 次 Web 检索，比传统的单次 LLM 裁判模式开销大得多，在大规模实时红队测试中的应用受限。
*   **对绝对拒绝类任务的局限（Refusal-Required Tasks）**：对于某些极度敏感、一律禁止生成的任务（如 CSAM、极危生物/化学武器制备），只要模型未拒绝并输出了内容（即使内容完全错误），从合规角度已构成 Failure；SEAV 的“按正确性打分”可能会对此类“答非所问但未拒绝”的风险产生低估。
*   **单回复视角与潜在意图盲区**：目前仅评估单轮回复，无法捕获多轮对话中累积的有害能力，也无法识别

高度伪装代码（Obfuscated Code）背后的潜在风险；同时对于极度依赖隐喻或隐式意图的攻击，时序提取阶段可能难以精准解耦离散步骤。
*   **依赖外部检索的稳健性**：评估质量在很大程度上依赖 Web 搜索引擎的检索能力。若外部检索无法覆盖高专业度领域（如高深生化合成或特定软件漏洞利用）的精准事实，或检索结果引入了噪声，可能会间接影响单步有效性验证的精度。

---

### 9. 对领域/后续研究的启发与未来方向

*   **越狱评估基准的升级**：提示后续研究在构建和改进越狱基准（Jailbreak Benchmarks）时，不应仅依赖传统 LLM 裁判的语义匹配度，而应将“操作可行性”与“事实核查”纳入标准化评估体系，避免评估结果“虚高”。
*   **多轮与复杂智能体扩展**：可将 SEAV 的时序依赖图与步骤校验机制扩展到多轮对话（Multi-turn Interaction）以及复杂智能体工作流（Agentic Workflows）的安全越狱评估中。
*   **评估效率与轻量化优化**：未来的研究可探索通过专用小模型微调（Fine-tuning Small Evaluator Models）或模型蒸馏技术，在大幅降低 API 调用频次与联网检索开销的前提下，保持对越狱攻击“操作有效性”的高精度校验。
