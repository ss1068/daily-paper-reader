## 摘要
运行时护栏对于可靠的大语言模型（LLM）部署至关重要，然而现有方法通常依赖独立的外部模型，这带来了额外的推理成本、安全信号延迟以及与能力日益增强的基座模型之间的能力不匹配问题。为了解决这些问题，我们提出了 SingProbe，这是一种轻量级的内生运行时防护机制，它直接复用 LLM 推理过程中产生的隐藏状态，并与自回归解码同步运行。在一个统一的框架内，SingProbe 以微乎其微的额外护栏推理开销，在 Token 级别持续预测查询意图、回复安全性及幻觉风险，提供了一种“免费午餐”式的解决方案。我们还推出了 SingStreamBench，这是一个旨在评估流式护栏能否在良性前缀上保持未激活状态、同时迅速检测出新出现的不安全内容的基准测试。大量实验表明，SingProbe 仅需 $\approx$2M 参数和 $<0.5\%$ 的额外开销，即可取得与规模大得多的独立护栏和专用幻觉检测器相当甚至更优的性能。除了被动检测外，我们还展示了 SingProbe 的评分能够预测未来的生成风险并指导受约束的安全解码。我们进一步通过 SingProbe-Med 将这一范式扩展至医学文本生成，仅在出现临床相关风险时选择性地触发风险导向的解码干预。综上所述，这些结果表明模型内部表示为生成阶段的监控与控制提供了一个高效且有效的接口。

## Abstract
Runtime guardrails are essential for reliable large language model (LLM) deployment, yet existing approaches typically rely on independent, external models that introduce additional inference cost, delayed safety signals, and a capacity mismatch with increasingly capable base models. To address these issues, we introduce SingProbe, a lightweight intrinsic runtime guard that directly reuses hidden states produced during LLM inference and operates alongside autoregressive decoding. Within a unified framework, SingProbe continuously predicts query intent, response safety, and hallucination risk at the token level with negligible additional guardrail inference overhead, offering a "free-lunch" solution. We further introduce SingStreamBench, a benchmark designed to assess whether streaming guardrails remain inactive on benign prefixes while promptly detecting emerging unsafe content. Extensive experiments show that SingProbe achieves competitive or superior performance compared with substantially larger standalone guardrails and specialized hallucination detectors, with only $\approx$2M parameters and $<0.5\%$ extra overhead. Beyond passive detection, we also show that SingProbe scores can anticipate future generation risk and guide constrained safe decoding. We further extend this paradigm to medical generation through SingProbe-Med, which selectively activates risk-directed decoding interventions only when clinically relevant risks emerge. Together, these results demonstrate that internal model representations provide an effective and efficient interface for generation-time monitoring and control.

### 1. 核心问题与研究动机（研究背景）

*   **面临的核心痛点**：在大型语言模型（LLM）的实际部署中，运行时安全护栏（Runtime Guardrails）对拦截有害内容和幻觉至关重要。但现有的独立外部护栏（External Guards）存在三大瓶颈：
    1.  **推理开销高与架构冗余**：独立护栏模型需要额外的参数量、重复的文本编码计算以及跨服务同步开销。
    2.  **安全信号延迟**：大多采用生成后（Post-hoc）或分块（Chunk-level）检测，缺乏 Token 级别的实时早期干预能力。
    3.  **模型容量不匹配**：护栏模型通常远小于基座 LLM，在处理长上下文或复杂 Agent 任务时难以准确理解复杂语义。
*   **研究核心思路**：借鉴“LLM 内部隐层状态（Hidden States）天然蕴含安全与事实性判别信号”的发现，作者提出了**内生护栏（Intrinsic Guard） SingProbe**。它直接复用基座 LLM 推理过程中已计算好的隐层特征，以极低开销在自回归解码的同时实现 Token 级的实时监控与控制。

### 2. 方法论与技术细节

*   **核心架构**：
    *   **隐层特征抽取与融合**：SingProbe 抽取基座模型特定 $S$ 层（默认均匀抽取浅、中、深 3 层）的隐层状态进行拼接，输入至基于 Query-Residual 聚合的轻量级多头注意力（MHA）预测头 $g_\theta$（仅约 2M 参数）。
    *   **统一多任务预测**：在每个 Token 位置同时输出：8 维查询意图得分（7 类细粒度风险 + 1 类安全）、1 维回复不安全得分、1 维回复幻觉得分。
*   **训练目标与损失函数**：
    *   **动态损失加权**：联合损失为 $\mathcal{L}_{\text{total}} = w_q \mathcal{L}_{\text{query}} + w_s \mathcal{L}_{\text{safety}} + w_h \mathcal{L}_{\text{hallu}}$。采用基于指数移动平均（EMA）的动态加权机制，根据各任务最近训练步的相对难度自动调整 $w_\tau(t)$，聚焦较难任务。
    *   **Query 意图损失**：应用 BCE 损失，并引入**软互斥损失（Soft Mutual-Exclusion Loss）**，惩罚 Safe 类别与最高风险类别同时预测为高分的情况。
    *   **自适应置信度 Token 加权聚合器**：针对回复级标签缺乏 Token 级真值的问题，根据 Token 预测值的离散度（Standard Deviation）动态调整加权强度 $\beta_r$。在初始化或离散度低时降级为均匀平均，避免噪声放大；在区分度提高后按 Softmax 赋予高风险 Token 更高权重。
*   **流式安全基准 SingStreamBench**：
    *   构建了包含 6 个 Tier 的分层评估基准（包含原始 QA、安全拒绝、安全前缀、复杂前缀与多问题嵌套等）。通过累加句子级前缀标注确定首个不安全起点（`Unsafe_Start_Index`），评估护栏能否在良性前缀保持默许并及时精准捕捉不安全内容的爆发点。
*   **SingProbe-Med（医疗场景按需干预）**：
    *   构建基于 AntAngelMed-100B 的医疗安全控管系统。结合干预适用性（$E_t$）、全局风险（$G_t$）、未来风险（$F_t$）、错误边界（$B_t$）四类内生信号组成蒸馏决策树规则。
    *   仅在识别到风险时激活基于 Top-K 约束的**引导解码转向（sGDS）**，利用与 Medical-Risk LoRA 导出的反专家（Anti-Expert）Logits 进行对比解码（Contrastive Decoding），在保证安全的同时避免全时长双分支推理。
