## 摘要
大语言模型（LLM）正日益广泛地部署于生产系统中，这也引发了人们对其可能遭受提示词注入和越狱攻击等对抗性操控的担忧。基于分类器的护栏（如 Prompt Guard 2）被广泛用作抵御此类攻击的第一道防线，但其内部决策逻辑对防御者和攻击者而言在很大程度上都是不透明的。本文展示了一项探索性案例研究，应用可解释人工智能（XAI）技术来分析 Prompt Guard 2 是如何区分恶意提示词与良性提示词的。我们进行了四个实验以对此问题进行实证探究。在 Vanilla Gradient 和 SHAP 归因方法的指导下，我们发现 Prompt Guard 2 的决策依赖于许多 Token 的累积贡献，而非少数主导 Token；然而，由显著性指导的同义词替换和句子级改写仅修改适度比例的文本即可翻转其预测结果，在某些情况下还能对底层 LLM 实现成功的越狱。数据集规模的显著性分析进一步表明，未被检测到的注入提示词系统性地缺乏分类器所依赖的词汇标记。我们讨论了这些发现对基于分类器的护栏设计与评估的启示，并指出旨在提高透明度的解释方法可能会同时降低构建成功对抗性绕过的成本。

## Abstract
Large language models (LLMs) are increasingly deployed in production systems, raising concerns about their exposure to adversarial manipulation through prompt injection and jailbreak attacks. Classifier-based guardrails, such as Prompt Guard 2, are widely used as a first line of defense against such attacks, but their internal decision logic is largely opaque to both defenders and attackers. This paper presents an exploratory case study that applies explainable artificial intelligence (XAI) techniques to analyze how Prompt Guard 2 distinguishes malicious from benign prompts.   We conduct four experiments to probe this question empirically. Guided by Vanilla Gradient and SHAP attributions, we find that Prompt Guard 2's decisions rely on the cumulative contribution of many tokens rather than a few dominant ones, yet saliency-guided synonym substitution and sentence-level paraphrasing can flip its predictions while altering only a moderate fraction of the text, in some cases yielding a successful jailbreak against the underlying LLM. A dataset-scale saliency analysis further shows that undetected injection prompts systematically lack the lexical markers the classifier relies on. We discuss the implications of these findings for the design and evaluation of classifier-based guardrails, and argue that explanation methods intended to support transparency can simultaneously lower the cost of constructing successful adversarial bypasses.

### 2. 论文提出的方法论（核心思想与细节）

核心思想是利用归因分析计算 Token 级的显著性（Saliency），并基于此指导渐进式文本扰动，评估分类器的鲁棒性与决策敏感点。

*   **XAI 归因技术**：
    *   **Vanilla Gradient（梯度法）**：计算模型输出相对于输入 Embedding 的梯度，衡量模型对特定 Token 的局部敏感度（模型对哪些词敏感）。
    *   **SHAP（扰动法）**：基于合作博弈论计算每个 Token 对预测结果的边际贡献值（每个词实际贡献了多少）。
*   **XAI 引导的四阶段实验流程**：
    1.  **Token Elimination（Token 剔除）**：按显著性降序逐个剔除词汇，测试模型预测是否依赖少数核心 Token。
    2.  **Synonym Replacement（同义词替换）**：利用辅助 LLM 构建高显著性词汇的同义词库，采取贪婪策略替换词汇，保留能最大幅降低注入类置信度 $P(\text{inj})$ 的同义词，测试语义保持下的抵抗力。
    3.  **Syntactic Modification（句法改写）**：拆分提示词句子，利用辅助 LLM 重述句法，完全避开高显著性词汇。
    4.  **Dataset-level Saliency Analysis（数据集级显著性分析）**：在真实数据集上批量计算归因，对比良性、已检测注入、未检测注入（漏报/假阴性）的词汇显著性分布。

### 6. 论文的主要结论与发现

1.  **分散决策机制**：Prompt Guard 2 的决策依赖于大量 Token 的累积贡献（显著性分布均匀，SD 指标低），而非依赖少数“触发词（Trigger Token）”。
2.  **易被同义词与重述绕过**：仅修改 24% 的文本（12 个同义词替换）或 9 个句子改写，即可使模型置信度从 0.9994 跌至 0.4457（判定为 benign），且修改后的提示词能**成功对 Llama 3.1 8B 实现真实越狱**。
3.  **词汇模式依赖与盲区**：数据集分析显示，护栏高度依赖 `ignore`, `previous`, `instructions`, `confidential` 等显示指令覆盖特征的显式标记。未被检出的注入攻击（假阴性）普遍缺乏这些标记，偏向于隐蔽的信息窃取模式。
4.  **跨语言脆弱性更显著**：在西班牙语测试中，仅需修改 18% 的文本（7 次同义词替换）即可绕过检测，表明护栏在非主导语言上的鲁棒性更差。
5.  **XAI 工具的双重性**：XAI 归因能够提供高价值的攻击导向信息，极大地降低攻击者构造对抗性绕过提示词的成本。
