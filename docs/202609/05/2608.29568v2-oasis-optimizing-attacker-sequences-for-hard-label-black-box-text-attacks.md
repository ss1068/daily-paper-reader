## 摘要
不同的攻击方法遵循不同的搜索轨迹，且在不同的样本子集上取得成功，而现有的硬标签黑盒文本攻击主要侧重于改进单个攻击者或对其进行人工组合。我们提出了 OASIS，一种用于在硬标签黑盒文本攻击中优化攻击者序列的方法。OASIS 首先在候选序列上执行一次性的双目标攻击链搜索，以平衡攻击成功率和扰动程度，随后在攻击链执行期间复用所选定的固定全局链。在多个数据集、受害者模型和大语言模型上的实验表明，OASIS 的表现持续优于强劲的独立基线以及简单的人工构建链。这些结果表明，攻击者组合不仅仅是一种实现细节上的选择，更是提升硬标签黑盒文本攻击效果的一个实用优化目标。

## Abstract
Different attack methods follow different search trajectories, they succeed on different subsets of samples, whereas existing hard-label black-box text attacks mainly focus on improving individual attackers or manually combining them. We present OASIS, a method for optimizing attacker sequences in hard-label black-box text attacks. OASIS first performs a one-time bi-objective attack chain search over candidate sequences to balance attack success rate and perturbation, and then reuses the selected fixed global chain during attack chain execution. Experiments across multiple datasets, victim models, and large language models show that OASIS consistently outperforms strong standalone baselines and simple manually constructed chains. These results suggest that attacker composition is not merely an implementation choice, but a practical optimization target for improving hard-label black-box text attacks.

### 2. 论文提出的方法论

#### 核心思想
OASIS 包含两个阶段：**本地攻击链搜索（Attack Chain Search）** 和 **攻击链执行（Attack Chain Execution）**。通过在本地小规模模型和数据集上执行一次性的多目标优化，搜索出一条兼顾高攻击成功率（ASR）与低扰动率（Pert）的固定全局攻击链，并在目标数据集和目标受害模型上重复使用该链。

#### 关键技术细节与算法流程
1.  **攻击链形式化（Attack Chain Formulation）**：
    *   从包含 $K=7$ 个候选攻击者的池子中，构建无重复元素的长度为 $L=3$ 的有序攻击链 $C = (a_{\sigma(1)}, a_{\sigma(2)}, a_{\sigma(3)})$。
    *   执行时，样本按顺序依次接受攻击者的处理，共享总查询预算 $B$。若前一个攻击者失败或生成的候选样本未通过质量约束（相似度/扰动率），则由下一个攻击者接替继续尝试。
2.  **基于 NSGA-II 的双目标搜索**：
    *   **目标函数**：同时追求 $\max \text{ASR}_L(C)$ 和 $\min \text{Pert}_L(C)$。
    *   **搜索过程**：在本地开发集（$N=100$）上，采用多目标遗传算法 NSGA-II 进行多代进化。设计了“保持顺序的交叉算子（Order-Preserving Crossover）”以及“位置交换/替换突变算子（Swap-or-Replace Mutation）”，以确保序列的有效性和无重复约束。
3.  **基于 TOPSIS 的最佳决策选择**：
    *   NSGA-II 终止后得到 Pareto 前沿解集。为避免选择偏向某一极端指标（如仅追求高 ASR 而导致文本质量极差）的方案，引入 TOPSIS（逼近理想解排序法）。
    *   通过计算标准化空间中每个解到正理想解（最高 ASR、最低 Pert）和负理想解的相对贴近度，自动筛选出平衡性最佳的单一全局链。
    *   最终选出的最佳固定链为：`HQAAttack → VIWHard → TextHacker`。

### 6. 论文的主要结论与发现

1.  **显著的性能超越**：在所有 20 个主实验测试场景中，OASIS 的 ASR 显著超越了最强的单体基线和手动组合链，同时扰动率（Pert）保持在同等或更优水平。
2.  **对 LLM 的强攻击力**：在 Qwen2.5 零样本和微调模型上，OASIS 分别取得了最高的攻击成功率，揭示了即便经过微调的大语言模型在面对优化后的攻击者序列时依然存在脆弱性。
3.  **“最强组合”不等于“最佳组合”**：单独挑选表现最强的 3 个攻击者（Best-3）效果不如 OASIS。原因在于强攻击者之间的成功攻击样本重叠度（Success-Set Overlap）非常高，而 OASIS 搜索出的序列成功捕获了不同搜索轨迹之间的互补性（Complementarity）。
4.  **极强的迁移性**：基于小型本地模型（BERT+MR）搜索出的固定攻击链，可以无缝迁移至结构完全不同的大模型（如 Qwen2.5）和长文本数据集上。

### 7. 优点

*   **视角新颖**：将硬标签攻击从“单个算法优化”推向“攻击者序列优化”的新维度，提出了显式利用攻击者互补性的理论框架。
*   **高实用性与低开销**：采用一次性离线搜索策略，搜索成本极低，搜索到的全局链可直接复用，免去了为每个新目标模型重新搜索的昂贵代价。
*   **严谨的多目标决策设计**：结合 NSGA-II 和 TOPSIS，有效解决了 ASR 和 Pert 之间的权衡难题，避免了极端离群解。
*   **评测全面**：覆盖了从传统 CNN/LSTM 到 Bert 以及最新的 Qwen2.5 大语言模型，基线数量丰富。

### 8. 不足与局限

*   **序列长度与候选池限制**：实验仅验证了固定长度 $L=3$ 的攻击链，且候选攻击者池数量为 $K=7$。更长或变长的动态攻击链尚未探讨。
*   **应用场景局限**：目前研究完全集中在**文本分类任务**上，尚未扩展到文本生成、摘要、问答或 LLM 的安全越狱（Jailbreaking）等更复杂的生成式任务。
*   **静态执行而非动态路由**：OASIS 采用的是统一的“固定全局链”，在攻击执行过程中，针对每个样本的具体特征并没有做到自适应的“动态调度”（如依据输入样本特征实时选择下一个最佳攻击者）。
