## 摘要
大语言模型（LLMs）已被用于生成恶意软件，但针对代码生成安全性的护栏有效性尚不明确。我们推出了 CS-Guard，这是首个系统评估代码生成安全护栏的基准测试。它涵盖了：1）文本到代码生成，包含 1000 个高质量恶意软件生成提示词、7 种越狱攻击，以及一种将恶意意图嵌入合法虚构软件开发场景的新型虚构场景攻击（FSA）；2）代码到代码生成，包含 331 个涵盖代码填充、代码补全和代码翻译的代码提示词。我们对 7 个大模型中的 9 种护栏进行了实证评估。研究发现，现有的护栏在应对恶意代码生成请求时表现不佳：在文本到代码生成方面，许多护栏在越狱攻击后的平均攻击成功率（ASR）达到约 50%；在代码到代码生成方面，基础大模型的平均 ASR 接近 100%，且在许多护栏中依然保持高位（14.4% 至接近 100%）。我们的 FSA 在许多护栏中也实现了接近 100% 的 ASR，这引发了对现实世界软件开发可靠性的重大担忧。为了支持未来的研究，CS-Guard 使用了一种模块化的三层护栏分类法，允许开发者注册护栏进行评估。我们发布了该基准测试和数据，以促进社区的进一步评估。

## Abstract
Large language models (LLMs) have been ex- ploited to generate malware, but the effective- ness of guardrails for code generation secu- rity remains unclear. We introduce CS-Guard, the first benchmark to systematically evalu- ate guardrails for code generation security. It covers 1) text-to-code generation with 1000 high-quality malware-generation prompts, 7 jailbreak attacks, and a novel fictional scenario attack (FSA) that embeds malicious intent in a legitimate fictional software-development sce- nario; and 2) code-to-code generation with 331 code prompts spanning code infilling, code completion, and code translation. We empiri- cally evaluate 9 guardrails across seven LLMs. We find that current guardrails perform poorly against malicious code-generation re- quests: for text-to-code, the average attack success rate (ASR) after jailbreaks reaches about 50% for many guardrails; for code-to- code, average ASR approaches 100% on base LLMs and remains high across many guardrails (14.4% to nearly 100%). Our FSA also achieves ASR close to 100% across many guardrails, raising major reliability concerns for real-world software development. To sup- port future research, CS-Guard uses a modular three-layer guardrail taxonomy that lets devel- opers register guardrails for evaluation. We release the benchmark and data to enable fur- ther community evaluation.

### 1. 核心问题与研究动机
随着大语言模型（LLM）在软件开发中的广泛应用，其被滥用于生成恶意软件的风险日益增加。尽管学术界和工业界提出了多种安全护栏（Guardrails）来防御此类滥用，但目前缺乏针对“代码生成安全”这一特定领域的系统性评估基准。现有研究多将恶意代码生成视为通用安全任务的子集，导致评估粒度粗糙，无法反映真实软件工程场景下的防御效果。

### 2. 方法论与核心思想
CS-Guard 旨在通过模块化和标准化的方式评估护栏的有效性，其核心贡献包括：
*   **三层护栏分类法**：定义了“类别层”（策略型、分类器型、内部型）、“操作层”（分类、生成）和“位置层”（输入、输出、灵活型），使基准测试具有高度的可扩展性。
*   **虚构场景攻击（FSA）**：这是论文的核心创新。FSA 将恶意意图隐藏在合法的软件开发场景中（例如将“植入后门”伪装成“远程启动救援代理”），绕过基于关键词的简单检测。
*   **评估流程**：采用 vLLM 进行推理，通过 LLM 自动标注（Labeler）结合人工抽样验证的方式，将响应分为“好（Good）”、“坏（Bad）”和“不明确（Unclear）”，并计算攻击成功率（ASR）。

*   **数据集**：
    *   **文本到代码（Text-to-Code）**：1000 个高质量恶意软件生成提示词（基于 CyberSecEval），辅以 7 种越狱攻击（如 EmojiAttack, CipherChat 等）及 FSA。
    *   **代码到代码（Code-to-Code）**：331 个样本，涵盖代码补全、填充和翻译，源自 RMCBench 和 Redcode-Gen。
*   **对比对象**：评估了 9 种主流护栏（如 LlamaGuard4, WildGuard, SmoothLLM, SelfReminder 等）在 7 个不同 LLM（包括 CodeLlama, DeepSeekCoder, Qwen3 等）上的表现。

*   **硬件**：开源模型实验在 3 张 NVIDIA RTX 5090 GPU 上运行。
*   **成本**：OpenAI API 调用花费约 630.3 美元，FSA 提示词构建花费约 160 美元。

### 5. 实验数量与充分性
*   **实验规模**：涵盖了从基础提示词到复杂越狱、从单轮到多轮（FSA-MT）的多种场景，实验覆盖面广。

### 6. 主要结论与发现
*   **防御失效**：现有护栏在面对恶意代码生成时表现极差。在文本到代码任务中，越狱攻击后的平均 ASR 约 50%；在代码到代码任务中，ASR 甚至接近 100%。

*   **多轮攻击（FSA-MT）**：在多轮对话中，即使是目前最强的护栏组合，其防御能力依然脆弱，ASR 依然很高。

### 7. 优点
*   **针对性强**：填补了代码生成安全领域缺乏专用基准的空白。
*   **创新性**：FSA 攻击方法非常贴近真实黑客的“社会工程学”手段，具有很高的实战参考价值。
*   **模块化设计**：三层分类法使得后续研究者可以轻松地将新的护栏模型接入该基准进行对比。
