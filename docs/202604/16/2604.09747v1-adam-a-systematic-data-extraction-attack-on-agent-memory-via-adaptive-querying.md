## 摘要
大语言模型（LLM）智能体已得到快速普及，并在广泛的应用中展现出卓越的能力。为了提高推理和任务执行能力，现代 LLM 智能体通常会集成记忆模块或检索增强生成（RAG）机制，使其能够进一步利用先前的交互或外部知识。然而，这种设计也引入了一系列关键的隐私漏洞：存储在记忆中的敏感信息可能会通过基于查询的攻击被泄露。尽管可行，但现有的攻击往往性能有限，攻击成功率（ASR）较低。在本文中，我们提出了 ADAM，这是一种新型隐私攻击，其特点是对受害者智能体记忆进行数据分布估计，并采用熵引导的查询策略来最大化隐私泄露。大量实验表明，我们的攻击显著优于现有最先进的方法，攻击成功率最高可达 100%。因此，这些结果强调了为当前 LLM 智能体开发鲁棒的隐私保护方法的紧迫需求。

## Abstract
Large Language Model (LLM) agents have achieved rapid adoption and demonstrated remarkable capabilities across a wide range of applications. To improve reasoning and task execution, modern LLM agents would incorporate memory modules or retrieval-augmented generation (RAG) mechanisms, enabling them to further leverage prior interactions or external knowledge. However, such a design also introduces a group of critical privacy vulnerabilities: sensitive information stored in memory can be leaked through query-based attacks. Although feasible, existing attacks often achieve only limited performance, with low attack success rates (ASR). In this paper, we propose ADAM, a novel privacy attack that features data distribution estimation of a victim agent's memory and employs an entropy-guided query strategy for maximizing privacy leakage. Extensive experiments demonstrate that our attack substantially outperforms state-of-the-art ones, achieving up to 100% ASRs. These results thus underscore the urgent need for robust privacy-preserving methods for current LLM agents.

#### 1. 核心问题与整体含义（研究动机和背景）
随着大语言模型（LLM）智能体在医疗、金融、法律等领域的广泛应用，其集成的**长期记忆模块**和**检索增强生成（RAG）机制**成为了隐私泄露的高风险点。这些模块存储了大量的用户历史交互和敏感信息。
*   **研究动机**：现有的隐私攻击（如 MEXTRA）多依赖静态、手工编写的提示词，效率低且容易被 LLM 的对齐机制过滤。此外，现有研究忽略了智能体记忆中**底层数据分布**对攻击效率的影响。
*   **核心问题**：如何系统性地、高效地从黑盒 LLM 智能体的记忆模块中提取完整的私有记录？

#### 2. 方法论：ADAM 攻击框架
ADAM（Adaptive querying and Distribution estimation to extract private data from Agent Memory）采用了一种**自适应查询**与**分布估计**相结合的策略。其核心流程如下：
*   **初始化**：从少量高层领域话题（种子锚点）开始，生成初始恶意查询。
*   **锚点提取（Anchor Extraction）**：从智能体的响应中提取关键词和主题，通过命名实体识别（NER）、规范化和去重形成候选锚点池。
*   **分布估计（Distribution Estimation）**：利用聚类算法（如 DBSCAN）估计记忆中的话题分布。通过更新选择概率，优先选择新提取的、未被充分探索的锚点，同时降低已选锚点的权重。
*   **锚点选择（Anchor Selection）**：采用主动学习中的 **加权 k-center 策略**，在嵌入空间中选择既有代表性又具多样性的锚点。
*   **熵引导查询生成（Entropy-guided Querying）**：利用辅助 LLM 生成查询。通过计算熵值来衡量候选查询的不确定性，优先选择那些最有可能触及未探索记忆区域（即信息增益最大）的查询。
*   **迭代优化**：不断根据观察到的响应修正对内存分布的估计，动态调整下一轮查询。

#### 6. 主要结论与发现
*   **性能卓越**：ADAM 在所有指标上均显著优于现有方法，在多个场景下实现了 **100% 的攻击成功率（ASR）**。
*   **分布估计的重要性**：首次证明了估计受害者记忆的数据分布能极大提升提取效率。
*   **防御脆弱性**：现有的防御机制（如关键词过滤或简单的查询重写）在面对 ADAM 这种基于语义和自适应策略的攻击时效果有限。
*   **规模效应**：受害者模型越大、记忆模块容量越大，隐私泄露的风险和效率反而越高。

#### 7. 优点（亮点）
*   **自适应性强**：不再依赖静态模板，而是根据反馈动态调整策略，具有极强的灵活性。

*   **系统性**：不仅提出了攻击，还深入探讨了底层机制和防御失效的原因。

*   **辅助模型依赖**：攻击效果部分取决于辅助 LLM（LLM attack）的生成能力，若辅助模型受到严格限制，攻击效率可能下降。
