## 摘要
随着基于大语言模型（LLM）的智能体在各个领域的广泛应用，其复杂性引入了新的安全威胁。现有的红队测试方法大多依赖于修改用户提示词，这缺乏对新数据的适应性，并可能影响智能体的性能。为了应对这一挑战，本文提出了 JailAgent 框架，该框架完全避免了对用户提示词的修改。具体而言，它通过三个关键阶段隐式地操纵智能体的推理轨迹和记忆检索：触发器提取、推理劫持和约束收紧。通过精确的触发器识别、实时自适应机制和优化的目标函数，JailAgent 在跨模型和跨场景环境中展现出了卓越的性能。

## Abstract
With the widespread application of LLM-based agents across various domains, their complexity has introduced new security threats. Existing red-team methods mostly rely on modifying user prompts, which lack adaptability to new data and may impact the agent's performance. To address the challenge, this paper proposes the JailAgent framework, which completely avoids modifying the user prompt. Specifically, it implicitly manipulates the agent's reasoning trajectory and memory retrieval with three key stages: Trigger Extraction, Reasoning Hijacking, and Constraint Tightening. Through precise trigger identification, real-time adaptive mechanisms, and an optimized objective function, JailAgent demonstrates outstanding performance in cross-model and cross-scenario environments.

### 2. 方法论：核心思想与关键技术
JailAgent 采用三阶段流水线来实现对智能体推理逻辑的“劫持”：

*   **阶段一：触发器提取 (Trigger Extraction)**
    *   **核心思想**：识别输入中对模型输出贡献最大的关键语义单元。
    *   **技术细节**：结合语法解析（spaCy）和子词对齐（BERT WordPiece），通过计算掩码前后的 **Log-probability 变化**和**步进式 KL 散度 (Step-wise KL)** 来评估短语和 Token 的重要性，从而提取出高贡献触发器。

*   **阶段二：推理劫持 (Reasoning Hijacking)**
    *   **核心思想**：通过一个“影子模型”学习目标智能体的决策偏好，并训练一个重排序器（Reranker）。
    *   **技术细节**：
        *   **数据工厂**：实时合成包含上下文、毒性响应（正样本）和良性响应（负样本）的三元组数据。
        *   **Reranker 训练**：使用轻量级评分头（MLP）配合冻结的 SentenceTransformer 编码器，通过 **Pairwise Ranking Loss** 进行快速微调，使模型在推理时倾向于选择偏离正常逻辑的候选答案。

*   **阶段三：约束收紧 (Constraint Tightening)**
    *   **核心思想**：在向量空间中优化触发器的嵌入表示，确保其在检索时的稳定性。
    *   **联合优化目标函数**：
        1.  **独特损失 (Particularity Loss)**：使触发器远离良性数据簇中心。
        2.  **聚类损失 (Clustering Loss)**：确保触发器内部各 Token 嵌入紧凑。
        3.  **分离损失 (Separability Loss)**：提高毒性样本的检索命中率。
        4.  **边界损失 (Margin Loss)**：扩大毒性样本与良性样本之间的相似度间距。
