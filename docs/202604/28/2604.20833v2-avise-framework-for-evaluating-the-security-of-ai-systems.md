## Abstract
As artificial intelligence (AI) systems are increasingly deployed across critical domains, their security vulnerabilities pose growing risks of high-profile exploits and consequential system failures. Yet systematic approaches to evaluating AI security remain underdeveloped. In this paper, we introduce AVISE (AI Vulnerability Identification and Security Evaluation), a modular open-source framework for identifying vulnerabilities in and evaluating the security of AI systems and models. As a demonstration of the framework, we extend the theory-of-mind-based multi-turn Red Queen attack into an Adversarial Language Model (ALM) augmented attack and develop an automated Security Evaluation Test (SET) for discovering jailbreak vulnerabilities in language models. The SET comprises 25 test cases and an Evaluation Language Model (ELM) that determines whether each test case was able to jailbreak the target model, achieving 92% accuracy, an F1-score of 0.91, and a Matthews correlation coefficient of 0.83. We evaluate nine recently released language models of diverse sizes with the SET and find that all are vulnerable to the augmented Red Queen attack to varying degrees. AVISE provides researchers and industry practitioners with an extensible foundation for developing and deploying automated SETs, offering a concrete step toward more rigorous and reproducible AI security evaluation.

随着AI系统（尤其是大语言模型 LLM）在关键领域的广泛应用，其安全性（如越狱攻击、提示词注入等）成为重大隐患。然而，现有的安全评估工具存在以下问题：
*   **缺乏系统性：** 许多工具仅针对特定模型或单一攻击类型，难以适应多模态或持续学习等新兴AI技术。
*   **随机性处理不足：** AI模型的输出具有概率性，单次测试无法准确反映安全状况。
*   **易用性与扩展性矛盾：** 强大的工具（如ART）学习曲线陡峭，而简单的扫描器又缺乏定制化能力。
**AVISE 的目标**是提供一个标准化的、支持多轮对话攻击、且能通过统计聚合多次运行结果来应对模型随机性的自动化评估框架。

### 2. 方法论：核心思想与技术细节
AVISE 采用分层模块化架构，主要包含两个核心层：
*   **编排层 (Orchestration Layer)：**

    *   **SET (Security Evaluation Test)：** 具体的安全评估测试类，如论文中实现的“红皇后”测试。
    *   **评估器 (Evaluators)：** 结合静态逻辑和**评估语言模型 (ELM)** 来判定目标模型是否被成功越狱。
    *   **执行引擎：** 管理测试生命周期，支持用户定义重复运行次数以获得统计学上的置信区间。
*   **交互层 (Interaction Layer)：**
    *   **连接器 (Connectors)：** 抽象化与目标API的通信，确保框架与不同部署环境的兼容性。
*   **关键技术：ALM 增强攻击**

    *   引入了**对抗语言模型 (ALM)**：在多轮对话中，ALM 会根据目标模型的实时回复动态调整攻击提示词，防止对话偏离预设的诱导路径，从而提高越狱成功率。

*   **测试场景：** 开发了包含 **25个测试用例** 的 Red Queen SET，涵盖制造假护照、伪造货币、清理犯罪现场、保险诈骗、走私毒品和制作管状炸弹等 6 大类有害行为。
*   **攻击策略：** 分为“职业角色扮演”（如假扮警察、律师）和“关系诱导”（如假扮朋友、亲戚）两种操纵策略。
*   **目标模型 (Benchmark)：** 评估了 9 种近期发布的开源指令微调模型，包括：

*   **对比实验：** 对比了“使用 ALM 增强”与“仅使用静态模板”两种模式下的攻击成功率。

*   **硬件环境：** 使用了 **2 台 NVIDIA Tesla P100 (16GB)** GPU。
*   **内存：** 234.4 GB RAM。

### 5. 实验数量与充分性
*   **实验规模：** 针对 9 个模型，每个模型分别在有/无 ALM 的情况下运行 25 个用例，总计进行了 **450 次多轮对话攻击实验**。
*   **客观性保障：** 
    *   引入了 **95% 二项比例置信区间 (Wilson Score)** 来量化失败率。
    *   **人工校验：** 研究人员对所有 ELM 的判定结果进行了人工审核，建立了混淆矩阵，计算了准确率、F1 分数和马修斯相关系数 (MCC)，证明了自动化评估的可靠性。

### 6. 主要结论与发现
*   **普遍脆弱性：** 所有受测模型在 ALM 增强的红皇后攻击面前均表现出不同程度的脆弱性。
*   **ALM 的显著作用：** 在没有 ALM 的情况下，目标模型大多能保持安全对齐（仅 7% 攻击成功）；但在 ALM 动态调整提示词后，**攻击成功率飙升至 47%**。
*   **模型表现差异：** 
    *   **最稳健：** Qwen 3.5 (35B) 和 Nemotron 3 Super (120B) 的失败率最低（约 8%-12%）。
    *   **最脆弱：** Ministral 3.2 (14B) 几乎每次都会被越狱（失败率 84%）。
*   **评估器效能：** 使用 Ministral 3 (3B) 作为 ELM 达到了 **92% 的分类准确率**，证明了小型模型在特定安全评估任务中的高效性。

### 7. 优点
*   **自动化与闭环：** 实现了从攻击生成、动态调整到结果判定的全流程自动化。
*   **统计严谨性：** 考虑了 AI 的随机性，通过多次运行和置信区间计算提供更科学的评估结果。
*   **高度模块化：** 框架设计允许轻松添加新的模型连接器、新的攻击向量或新的评估逻辑。
*   **开源贡献：** 提供了完整的源代码和实验报告，促进了学术界和工业界的复现。

### 8. 不足与局限
*   **覆盖范围有限：** 目前仅深入展示了针对 LLM 的越狱测试，对多模态和持续学习系统的支持尚处于规划阶段。
