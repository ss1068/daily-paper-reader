## 摘要
随着人工智能（AI）系统在关键领域的部署日益广泛，其安全漏洞带来了日益增长的高风险利用和重大系统故障的风险。然而，评估 AI 安全性的系统化方法仍不完善。在本文中，我们介绍了 AVISE（AI 漏洞识别与安全性评估），这是一个用于识别 AI 系统和模型漏洞并评估其安全性的模块化开源框架。作为该框架的演示，我们将基于心智理论（theory-of-mind）的多轮“红皇后”攻击扩展为对抗性语言模型（ALM）增强攻击，并开发了一套自动化的安全性评估测试（SET），用于发现语言模型中的越狱漏洞。该 SET 包含 25 个测试用例和一个评估语言模型（ELM），用于判断每个测试用例是否能够实现对目标模型的越狱，并达到了 92% 的准确率、0.91 的 F1 分数以及 0.83 的马修斯相关系数。我们使用 SET 评估了九个近期发布的、规模各异的语言模型，发现所有模型在不同程度上都容易受到增强型“红皇后”攻击的影响。AVISE 为研究人员和行业从业者提供了一个可扩展的基础，用于开发和部署自动化 SET，为实现更严谨、可重复的 AI 安全性评估迈出了具体的一步。

## Abstract
As artificial intelligence (AI) systems are increasingly deployed across critical domains, their security vulnerabilities pose growing risks of high-profile exploits and consequential system failures. Yet systematic approaches to evaluating AI security remain underdeveloped. In this paper, we introduce AVISE (AI Vulnerability Identification and Security Evaluation), a modular open-source framework for identifying vulnerabilities in and evaluating the security of AI systems and models. As a demonstration of the framework, we extend the theory-of-mind-based multi-turn Red Queen attack into an Adversarial Language Model (ALM) augmented attack and develop an automated Security Evaluation Test (SET) for discovering jailbreak vulnerabilities in language models. The SET comprises 25 test cases and an Evaluation Language Model (ELM) that determines whether each test case was able to jailbreak the target model, achieving 92% accuracy, an F1-score of 0.91, and a Matthews correlation coefficient of 0.83. We evaluate nine recently released language models of diverse sizes with the SET and find that all are vulnerable to the augmented Red Queen attack to varying degrees. AVISE provides researchers and industry practitioners with an extensible foundation for developing and deploying automated SETs, offering a concrete step toward more rigorous and reproducible AI security evaluation.

### 2. 方法论：AVISE 框架架构
AVISE 采用 Python 开发，由两个核心层组成：
*   **编排层（Orchestration Layer）**：
    *   **BaseSETPipeline**：定义了测试的生命周期（初始化、执行、评估、报告），确保不同测试的标准化。
    *   **SET（安全评估测试）**：具体的测试逻辑实现。论文重点展示了扩展后的“红皇后”（Red Queen）攻击。
    *   **评估器（Evaluators）**：利用评估语言模型（ELM）自动判断目标模型是否被成功越狱。
    *   **执行引擎与报告生成器**：管理执行流程并生成包含 AI 摘要和修复建议的人类可读报告。
*   **交互层（Interaction Layer）**：
    *   **连接器（Connector）**：通过 API 与目标系统通信，支持黑盒评估，模拟真实攻击场景。
*   **关键技术创新——ALM 增强攻击**：
    *   论文引入了**对抗性语言模型（ALM）**。在多轮攻击中，ALM 会根据目标模型的实时回复动态调整后续的攻击提示词（Prompt），以防止对话偏离预设的攻击上下文，从而显著提高攻击成功率。

### 3. 实验设计
*   **测试场景**：开发了包含 **25 个测试用例**的 Red Queen SET，涵盖 14 个有害类别（如制造假护照、洗钱、制造炸弹等）。
*   **攻击策略**：分为“职业型”（如假扮警察、老师）和“关系型”（如假扮朋友、亲戚）两种社会工程学伪装。
*   **对比实验**：
    *   **基准测试**：不使用 ALM 的原始多轮模板攻击。
    *   **实验组**：使用 ALM 动态调整提示词的增强型攻击。
*   **评估指标**：准确率（Accuracy）、F1 分数、马修斯相关系数（MCC）以及失败率（即攻击成功率 ASR）。

*   **硬件环境**：Ubuntu 24.04 系统，配备 **2 台 NVIDIA Tesla P100 (16 GB) GPU**，以及 234.4 GB RAM。
*   **模型部署**：使用 Ollama 部署目标模型。
*   **辅助模型**：ALM 和 ELM 均采用 3B 参数的 **Ministral 3** 指令微调版模型。

### 5. 实验数量与充分性
*   **实验规模**：对 **9 款**近期发布的开源指令微调模型进行了评估，包括 Llama 3.1/3.2/3.3 系列、Ministral 3、Mistral 3.2、Qwen 3/3.5 以及 NVIDIA Nemotron 3 系列。
*   **充分性评价**：
    *   实验涵盖了从 3B 到 120B 不同参数规模的模型，具有较好的代表性。
    *   每款模型均在“有 ALM”和“无 ALM”两种模式下运行，总计进行了数百次多轮对话测试。
    *   所有自动评估结果均经过了**人工校验**，以验证 ELM 的分类准确性，实验设计较为严谨、客观。

### 6. 主要结论与发现
*   **普遍脆弱性**：所有被测模型在不同程度上都容易受到 ALM 增强型红皇后攻击的影响。
*   **ALM 的显著作用**：在没有 ALM 辅助时，目标模型仅在 7% 的情况下产生有害输出；而加入 ALM 后，攻击成功率飙升至 **47%**。
*   **模型表现差异**：
    *   **最稳健模型**：Qwen 3.5 35B 和 Nemotron 3 Super 120B 表现出最强的抗攻击能力（失败率仅为 8%-12%）。
    *   **最脆弱模型**：Ministral 3 14B 的失败率高达 84%。
*   **评估器效能**：ELM 在判断越狱是否成功方面表现优异，准确率达到 **92%**，证明了自动化安全评估的可行性。

### 7. 优点与亮点
*   **自动化与动态化**：通过 ALM 解决了多轮攻击中对话容易“跑偏”的问题，使自动化黑盒测试更接近真实的人类黑客攻击。
*   **模块化设计**：框架易于扩展，未来可轻松集成针对图像、音频或持续学习系统的测试用例。
*   **实用性强**：生成的报告不仅包含技术日志，还提供 AI 生成的漏洞摘要和修复建议，对行业从业者非常友好。

### 8. 不足与局限
*   **样本量限制**：虽然覆盖了 9 款模型，但 25 个测试用例的样本量相对较小，可能无法覆盖所有边缘情况。
*   **评估器偏差**：ELM 在处理模糊指令（如目标模型提供防御性建议但包含敏感细节）时可能存在误报或漏报。
*   **双重用途风险**：作为一个开源的攻击性测试框架，它可能被恶意行为者利用来寻找并攻击已部署的系统（尽管作者强调了负责任披露的重要性）。
*   **算力成本**：使用语言模型作为评估器（ELM）和攻击者（ALM）虽然灵活，但相比静态检测会消耗更多的计算资源。
