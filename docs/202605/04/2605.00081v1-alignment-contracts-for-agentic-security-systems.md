## 摘要
代理式安全系统越来越多地将大语言模型（LLM）规划器与能够发现、验证和报告漏洞的工具相结合。这产生了一个非对称控制问题：系统在授权参与范围内应保持强大的攻击能力，而在范围之外则必须禁止这些能力。现有的护栏提供了有用的策略控制，但它们并未将这一边界转化为针对可观测效应的一等形式化合约。我们引入了对齐合约，这是一个用于指定和强制执行可观测效应轨迹行为约束的框架。合约定义了范围、允许和禁止的效应、资源预算以及披露策略。我们为该语言赋予了有限轨迹语义，将满足性表征为具有有限违规见证的安全属性，开发了用于模块化合约工程的精化和单向组合规则，并证明了准入检查是可判定的。我们针对以 Web 为中心的代理式安全工作流实例化了该框架，并展示了相同的结构如何扩展到其他效应配置文件。在显式的效应可观测性假设下（即所有 $\SigmaEff$-效应均受调解），可靠性定理对代理模型进行了量化，并为受调解的 $\SigmaEff$-效应提供了保证，包括监控实现轨迹的执行可靠性。我们还陈述了一个假设提升的自适应结果，并通过不可判定性转移和可观测性边界定理形式化了限制。一个 Lean 4 形式化制品验证了论文中使用的核心形式化定理。

## Abstract
Agentic security systems increasingly combine LLM planners with tools that can discover, validate, and report vulnerabilities. This creates an asymmetric control problem: the system should retain strong offensive capability inside an authorized engagement, while the same capabilities must be denied outside scope. Existing guardrails provide useful policy controls, but they do not make this boundary a first-class formal contract over observable effects.   We introduce alignment contracts, a framework for specifying and enforcing behavioral constraints over observable effect traces. A contract defines scope, allowed and forbidden effects, resource budgets, and disclosure policies. We give the language finite-trace semantics, characterize satisfaction as a safety property with finite violation witnesses, develop refinement and one-way composition rules for modular contract engineering, and show that admissibility checking is decidable. We instantiate the framework for web-focused agentic security workflows and show how the same structure extends to other effect profiles.   Under an explicit Effect Observability Assumption, where all $\SigmaEff$-effects are mediated, the soundness theorem quantifies over the agent model and gives guarantees for mediated $\SigmaEff$-effects, including enforcement soundness for monitor-realized traces. We also state an assumption-lifted adaptation result and formalize limits through undecidability transfer and observability-boundary theorems. A Lean 4 artifact checks the formal core theorems used by the paper.

#### 1. 核心问题与整体含义（研究动机和背景）
随着大语言模型（LLM）从单纯的聊天助手演变为能够规划、执行和验证安全测试的“自主代理”（Agentic Systems），出现了一个**非对称控制难题**：
*   **需求**：在授权的渗透测试任务中，代理必须具备强大的攻击能力（如扫描、漏洞利用验证）。
*   **风险**：同样的攻击能力如果作用于非授权目标、使用非法手段或向攻击者泄露数据，则是极度危险的。
*   **现状**：现有的安全护栏（Guardrails）多基于启发式规则或意图分类，缺乏将“授权边界”作为一等公民的形式化契约，难以在对抗性环境（如提示词注入攻击）下提供严谨的安全保证。

#### 2. 方法论：核心思想与技术细节
论文提出了**对齐合约（Alignment Contracts）**框架，旨在通过监控代理产生的“可观测效应轨迹”来强制执行行为约束。

*   **核心思想**：将安全约束从“猜测模型意图”转向“调解外部效应”。只要代理的所有外部操作（网络请求、文件访问等）都经过监控器，就能确保其行为符合预定义的合约。
*   **合约定义**：一个合约被定义为一个八元组 $C = \langle S, E_{\text{allow}}, E_{\text{forbid}}, B, D, \text{Res}, \text{cost}, \text{flows} \rangle$：
    *   **$S$ (Scope)**：范围谓词，定义哪些目标（如 IP、域名）是授权的。
    *   **$E_{\text{allow}} / E_{\text{forbid}}$**：允许或显式禁止的效应描述符（如仅允许 GET 请求，禁止执行系统命令）。
    *   **$B$ (Budget)**：资源预算（如最大请求次数、流量限制）。
    *   **$D$ (Disclosure)**：披露政策，规定敏感数据流向哪些授权接收端。
    *   **Res, cost, flows**：用于资源核算和数据流提取的辅助函数。
*   **关键技术细节**：
    *   **有限轨迹语义**：将执行过程视为事件序列，定义“准入检查”（Admissibility）函数 $Adm(e, \tau, C)$，判断在给定历史轨迹 $\tau$ 下，新事件 $e$ 是否合法。
    *   **效应可观测性假设 (EOA)**：这是理论成立的前提，即所有关键效应必须被监控器拦截和调解。

*   **执行可靠性**：在 EOA 假设下，无论 LLM 内部状态如何（即使被完全控制），监控器都能确保实现的效应轨迹满足合约。

#### 7. 优点（亮点）
*   **严谨性**：将 LLM 代理的对齐问题转化为形式化的安全属性验证，并提供了机械化证明。
*   **信任转移**：将安全信任从不可预测的“黑盒”模型转移到了可审计、确定性的“白盒”监控器上。
*   **实用性**：合约语言设计贴近安全行业的实际需求（如渗透测试授权书的结构）。

#### 8. 不足与局限
*   **假设依赖**：高度依赖“效应可观测性假设”。如果代理能通过内核漏洞或未建模渠道绕过监控，所有保证失效。
*   **语义缺失**：目前的框架主要关注效应的“参数”（如目标、方法），对效应“内容”（如具体的攻击载荷语义）的深度检测仍需依赖非形式化的语义分析层。
*   **静态性**：核心模型假设合约在任务期间是静态的，对于需要动态调整授权的复杂场景，尚需进一步扩展。
*   **隐蔽信道**：无法处理利用合法操作频率或载荷编码实现的隐蔽数据泄露。
