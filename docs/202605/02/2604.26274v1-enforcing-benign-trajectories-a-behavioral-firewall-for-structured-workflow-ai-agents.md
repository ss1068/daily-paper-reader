## 摘要
由大语言模型驱动的结构化工作流智能体针对敏感的外部环境执行工具调用。我们提出了 \codename，一种遥测驱动的行为异常检测防火墙。借鉴基于序列的入侵检测，\codename 将经过验证的良性工具调用遥测数据编译为参数化确定性有限自动机 (pDFA)。该模型定义了允许的工具序列、序列上下文和参数边界。在运行时，轻量级网关通过 $O(1)$ 状态转移结构查找来强制执行这些边界，从而将计算开销巨大的分析完全转移到线下。在 Agent Security Bench (ASB) 上的评估显示，\codename 在五个场景中的宏平均攻击成功率 (ASR) 为 5.6%。在三个结构化工作流中，ASR 降至 2.2%，优于最先进的无状态扫描器 Aegis（其 ASR 为 12.8%）。\codename 在结构化设置下的多步攻击和上下文序列攻击中实现了 0% 的 ASR。此外，针对 1,000 个算法拼接的窃取有效载荷，仅 1.4% 匹配有效的结构路径，且所有这些路径均未能通过端到端字符串参数防护（14 条幸存路径中成功次数为 0，95% 置信区间 [0%, 23.2%]）。\codename 每次调用仅引入 2.2 毫秒的延迟（比 Aegis 快 3.7 倍），同时在良性工作负载上保持 2.0% 的良性任务失败率 (BTFR)。对行为轨迹建模有效地压缩了可用的攻击面，但未维护的连续参数边界仍容易受到同义词替换攻击的影响（逃逸率为 18%）。因此，敏感参数的精确匹配白名单最终承担了防御执行的最后重任。

## Abstract
Structured-workflow agents driven by large language models execute tool calls against sensitive external environments. We propose \codename, a telemetry-driven behavioral anomaly detection firewall. Drawing on sequence-based intrusion detection, \codename\ compiles verified benign tool-call telemetry into a parameterized deterministic finite automaton (pDFA). The model defines permitted tool sequences, sequential contexts, and parameter bounds. At runtime, a lightweight gateway enforces these boundaries via an $O(1)$ state-transition structural lookup, shifting computationally expensive analysis entirely offline. Evaluated on the Agent Security Bench (ASB), \codename\ achieves a 5.6\% macro-averaged attack success rate (ASR) across five scenarios. Within three structured workflows, ASR drops to 2.2\%, outperforming Aegis, a state-of-the-art stateless scanner, at 12.8\%. \codename\ achieves 0\% ASR on multi-step and context-sequential attacks in structured settings. Furthermore, against 1,000 algorithmically spliced exfiltration payloads, only 1.4\% matched valid structural paths, all of which failed end-to-end string parameter guards (0 successes out of 14 surviving paths, 95\% CI [0\%, 23.2\%]). \codename\ introduces just 2.2~ms of per-call latency (a 3.7$\times$ speedup over \textsc{Aegis}) while maintaining a 2.0\% benign task failure rate (BTFR) on benign workloads. Modeling the behavioral trajectory effectively collapses the available attack surface, but unmaintained continuous parameter bounds remain vulnerable to synonym-substitution attacks (18\% evasion rate). Thus, exact-match whitelisting of sensitive parameters ultimately bears the final defensive load against execution.

*   **核心问题**：现有的 AI 智能体（Agent）防火墙大多是**无状态（Stateless）**的，即孤立地评估每一个工具调用（Tool Call）。
*   **研究背景**：攻击者可以利用“上下文序列注入攻击”（Context-Sequential Injection Attacks），通过一系列在语法上正确且单独看均属良性的调用（例如：先读取数据库，再发送邮件）来实现恶意目的。
*   **研究动机**：由于无状态防火墙缺乏对调用序列上下文的理解，无法识别这种违背正常业务逻辑的“恶意轨迹”。因此，需要一种能够强制执行“良性行为轨迹”的防御机制。

### 2. 论文提出的方法论：Praetor
Praetor 是一种遥测驱动的行为异常检测防火墙，其核心思想是将智能体的安全边界从“单次调用验证”扩展到“执行路径完整性验证”。
*   **核心思想**：利用**参数化确定性有限自动机（pDFA）**对良性行为进行建模。
*   **关键技术细节**：
    *   **离线剖析阶段（Profiling）**：从验证过的良性遥测数据中提取轨迹。使用 **w-gram 上下文**（默认 w=3）定义状态，即当前状态由当前工具名及前 w 个工具序列共同决定。
    *   **参数守卫（Parameter Guards）**：为每个状态转移合成参数模式。
        *   *数值型*：学习取值区间并加入松弛因子。
        *   *字符串型*：使用 SBERT 将字符串映射为向量，计算质心和半径（r-ball）。
        *   *类别型*：执行精确匹配白名单。
    *   **运行时强制执行（Runtime Enforcement）**：网关作为侧车（Sidecar）部署，对每次工具调用进行 $O(1)$ 时间复杂度的状态转移查找。若调用不符合 pDFA 定义的路径或参数范围，则立即拦截并记录到加密审计日志中。

### 6. 主要结论与发现
*   **防御性能**：在结构化工作流中，Praetor 将攻击成功率（ASR）从 Aegis 的 12.8% 降低至 **2.2%**。在多步窃取攻击中实现了 **0% ASR**。
*   **运行效率**：单次调用延迟仅 **2.2 毫秒**，比 Aegis 快 3.7 到 28.3 倍，且延迟不随状态机规模增加而增长（$O(1)$ 特性）。
*   **关键发现**：结构化路径约束能极大压缩攻击面，但**字符串参数的精确匹配**是防御语义逃逸（如语义相似的恶意载荷）的最后防线。

### 7. 优点
*   **状态感知（Stateful）**：填补了现有防火墙无法处理序列化攻击的空白。
*   **极高性能**：通过离线编译分析、在线查表的架构，消除了运行时推理的负担。
*   **低侵入性**：作为侧车部署，无需修改 Agent 内部逻辑或模型权重。
*   **确定性**：相比基于 LLM 的检测器，Praetor 的决策是确定性的，易于审计。

### 8. 不足与局限
*   **高熵场景失效**：在任务极其开放、不可预测的场景（如通用研究助手）中，ASR 会显著上升（最高达 12.6%），因为此时良性行为轨迹过于发散。
*   **语义逃逸风险**：连续的字符串参数边界（r-ball）容易受到同义词替换攻击（18% 的逃逸率），需要依赖手动维护的敏感参数白名单。
*   **冷启动与投毒风险**：系统安全性高度依赖于初始训练轨迹的纯净度，若训练数据被投毒，防火墙将失效。
*   **维护成本**：当 Agent 功能更新时，需要人工介入审批新路径以更新 pDFA。
