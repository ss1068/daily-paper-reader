## 摘要
随着基于大语言模型（LLM）的智能体越来越多地被部署用于执行复杂的现实任务，它们面临着一类日益增多的攻击。这些攻击利用用户-智能体-环境之间长时间的交互，来实现单轮对话场景下难以达成的恶意目标。这种长程（long-horizon）威胁对 LLM 智能体在关键领域的安全部署构成了重大风险。在本文中，我们提出了 MAGE（Memory As Guardrail Enforcement），这是一个旨在应对各种长程威胁的新型防御框架。受系统安全中“影子栈”（shadow stack）抽象概念的启发，MAGE 维护了一个专门的、以安全为中心的智能体内存，用于提取并保留智能体整个执行轨迹中与安全相关的关键上下文，并利用该影子内存（shadow memory）在待执行操作执行前主动评估其风险。广泛的评估表明，MAGE 在多种长程威胁的检测准确率上显著优于现有防御措施，实现了对大多数攻击的早期检测，且对智能体效用的开销几乎可以忽略不计。据我们所知，MAGE 是首个利用智能体内存方法检测和缓解长程威胁的框架，为这一关键挑战建立了新的范式，并为未来的研究开辟了充满前景的方向。

## Abstract
As large language model (LLM)-powered agents are increasingly deployed to perform complex, real-world tasks, they face a growing class of attacks that exploit extended user-agent-environment interactions to pursue malicious objectives improbable in single-turn settings. Such long-horizon threats pose significant risks to the safe deployment of LLM agents in critical domains. In this paper, we present MAGE (Memory As Guardrail Enforcement), a novel defensive framework designed to counter a wide range of long-horizon threats. Inspired by the "shadow stack" abstraction in systems security, MAGE maintains a dedicated, safety-focused agentic memory that distills and retains safety-critical context across the agent's full execution trajectory, leveraging this shadow memory to proactively assess the risk of pending actions prior to their execution. Extensive evaluation demonstrates that MAGE substantially outperforms existing defenses across diverse long-horizon threats in detection accuracy, achieves early-stage detection for the majority of attacks, and introduces only negligible overhead to agent utility. To our best knowledge, MAGE represents the first framework to detect and mitigate long-horizon threats using an agentic memory approach, establishing a new paradigm for this critical challenge and opening promising directions for future research.

### 2. 方法论：核心思想与关键技术
*   **核心思想**：借鉴系统安全中的“影子栈”（Shadow Stack）概念，MAGE 运行一个并行的、专门用于安全审计的**影子内存**。它不参与任务逻辑，而是专门提炼和保留与安全相关的关键上下文。
*   **关键组件**：
    *   **内存管理器 ($M$)**：负责将当前轮次的动作、观测和指令提炼并更新到影子内存中。
    *   **裁判 ($J$)**：在动作执行前，结合影子内存评估该动作的风险，决定“批准”或“拒绝”，并给出理由。
*   **算法流程**：
    1.  智能体提出待执行动作 $a_t$。
    2.  $M$ 更新影子内存 $m_t$。
    3.  $J$ 基于 $m_t$ 对 $a_t$ 进行风险评估。
    4.  若 $J$ 批准，则执行动作并获取环境反馈；若拒绝，则拦截动作并向用户报告。
*   **优化技术（强化学习）**：
    *   使用 **GRPO**（组相对策略优化）算法。
    *   **奖励设计**：包括裁判奖励（判断准确性）、影子内存奖励（考虑未来判断的折扣奖励）、格式惩罚和长度惩罚（保持内存简洁）。
    *   **轮次级强化学习**：将奖励归因到具体的生成阶段（内存更新或风险评估），避免奖励劫持。

### 6. 主要结论与发现
*   **高安全性**：MAGE 将 STAC 攻击的成功率（ASR）从 100% 降低到 8.3%，将 PI2 攻击的成功率降低到 0%。
*   **低效用损失**：在保持极高防御力的同时，良性任务的成功率（BU）保持在 94% 以上（用户对手场景）或与无防御状态持平（环境对手场景）。

*   **早期检测**：大多数攻击在第一轮或恶意动作提出的瞬间即被拦截，平均检测延迟接近 0。

### 7. 优点（亮点）
*   **范式创新**：首次将“智能体记忆”作为安全原语，解决了长程攻击中意图稀释的问题。
*   **即插即用**：无需修改智能体核心模型或推理流程，作为外部组件集成。
*   **可解释性**：裁判不仅给出决策，还基于影子内存提供人类可读的违规理由。
*   **防御深度**：通过影子内存的提炼，能够识别并过滤掉试图操纵防御组件的自适应指令。

### 8. 不足与局限
*   **固定模式风险**：目前的影子内存主要关注用户意图和已知攻击模式，对于全新的、未见过的攻击类型可能存在泛化风险。
*   **单智能体限制**：研究目前集中在单智能体场景，在多智能体协同（Multi-agent systems）中的复杂交互防御尚未探讨。
*   **依赖训练质量**：影子内存的提炼能力高度依赖于强化学习阶段所覆盖的轨迹多样性。
*   **应用领域**：主要在办公和金融场景验证，对于代码执行、物理机器人控制等更具实时性和高风险领域的适用性有待进一步验证。
