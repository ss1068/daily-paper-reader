## 摘要
大语言模型（LLMs）已被集成到复杂的生态系统（如代码智能体）中，而间接提示注入（IPI）攻击已成为其安全部署的关键障碍。攻击者利用 LLM 无法区分“指令”与“数据”的特性，通过恶意注入的指令来操纵模型。然而，现有的防御措施面临着难以解决的安全与效用权衡：大多数防护栏要么导致高延迟，要么遭受严重的过度拒绝。在本文中，我们首先通过理论和实证证据证明了 LLM 本质上可以将指令与数据分离。受此启发，我们提出了 AEGIS（用于注入屏蔽的自适应集成防护）。AEGIS 提取指令敏感投影器以识别恶意指令，并利用统一多层共识机制，聚合跨网络深度的拓扑差异信号。实证评估表明，与基准模型相比，AEGIS 在针对启发式和基于优化的攻击方面均取得了显著的检测性能，凸显了其缓解 IPI 的潜力。代码可在 https://github.com/xaddwell/AEGIS 获取。

## Abstract
Large Language Models (LLMs) have been integrated into complex ecosystems (e.g., Code Agents), while Indirect Prompt Injection (IPI) attacks have emerged as critical barriers to their safe deployment. Attackers exploit LLMs' indistinguishability between "instructions" and "data" to manipulate LLMs via maliciously injected instructions. Existing defenses, however, face an intractable safety-utility trade-off: most guardrails either incur high latency or suffer from severe over-refusal. In this paper, we first demonstrate that LLMs can separate instruction from data intrinsically with both theoretical and empirical evidence. Inspired by this insight, we propose AEGIS (Adaptive Ensemble Guard for Injection Shielding). AEGIS extracts instruction-sensitive projectors to identify malicious instructions and leverages a Unified Multi-Layer Consensus mechanism that aggregates topologically distinct signals across the network depth. Empirical evaluations show that AEGIS achieves remarkable detection performance against both heuristic and optimization-based attacks compared to baselines, highlighting its potential to mitigate IPI. Code is available at https://github.com/xaddwell/AEGIS

### 2. 方法论：AEGIS 框架
AEGIS 的核心思想是利用指令微调（SFT）后模型内部形成的**潜指令流形（Latent Instruction Manifolds）**进行防御。
*   **指令敏感投影器（Instruction Projector）**：
    *   **几何假设**：预训练使知识表征占据高维、高熵流形，而指令微调使指令表征坍缩到低维、紧凑的算子子空间。
    *   **技术细节**：利用 Fisher 准则寻找最优投影方向 $w$，旨在最大化指令信号与知识噪声中心点之间的距离，同时最小化指令类内部的方差。通过收缩估计（Ledoit-Wolf shrinkage）处理协方差矩阵，提取出稳定的“指令意图”特征。
*   **分布感知安全校准**：
    *   不设定固定阈值，而是根据良性知识数据集的投影统计分布，利用分位数函数动态设定决策边界，从而在数学上保证极低的误报率（FPR）。
*   **统一多层共识机制（Multi-Layer Consensus）**：
    *   **核心流程**：在模型的多个中间层（如中间深度的 3-7 层）提取信号。
    *   **投票策略**：提供“硬投票”（统计超过阈值的层数）和“软投票”（聚合各层的标准化得分）两种模式。通过 Hoeffding 不等式证明，随着参与投票的层数增加，系统整体的误报率会呈指数级下降。

*   **性能卓越**：AEGIS 在大多数任务上达到了 **>98% 的准确率**，同时将误报率（FPR）控制在 **<1%**，远优于 PromptGuard 等高误报率方法。
*   **打破权衡**：成功解决了安全与效用的矛盾，在保持高检测率的同时，几乎不损害模型处理正常查询的能力。

### 7. 优点
*   **理论支撑强**：基于线性表征假设和 Fisher 准则，并给出了多层集成的理论误差界限。
*   **轻量且无需训练**：不需要重新训练 LLM，仅需极少量样本进行离线校准，部署成本极低。
*   **鲁棒性高**：通过多层共识机制，能够过滤掉单层中可能出现的瞬时噪声，对复杂的优化式攻击也有很好的防御效果。

### 8. 不足与局限
*   **白盒依赖**：防御者必须能够访问模型的内部激活值（Hidden States），这使得该方法**无法直接应用于闭源 API 服务**（如 GPT-4 原始接口）。
*   **层独立性假设**：理论推导中假设各层之间近似独立，但在实际深度网络中，层间存在强功能依赖，这可能导致理论误差界限比实际情况更乐观。
*   **计算开销**：虽然比 LLM 裁判快，但相比于纯文本分类器（如 DistilBERT），仍存在一定的计算延迟和显存占用。
