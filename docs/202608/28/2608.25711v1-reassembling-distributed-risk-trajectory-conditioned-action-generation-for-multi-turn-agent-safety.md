## 摘要
使用工具的 LLM 智能体将安全风险从生成的文本扩展到了影响外部系统的动作。在多轮分解攻击下，有害目标可能被分散到各个看似合理的请求和工具调用中，只有通过累积的轨迹才能显现出来。现有的防御措施要么依赖辅助在线推理来恢复长程安全证据，要么在生成后评估动作，这通常会产生额外的推理开销，或依赖于特定运行时的动作表示。我们提出了“重组分布式风险”（ReDiR），这是一种生成时防御机制，它以轨迹级的安全证据为条件来生成动作。在每个动作之前，ReDiR 将当前轨迹压缩为紧凑的潜在安全表示，并将其注入冻结的基础模型中。该表示通过同模型、跨视图监督进行学习，其中来自显式任务视图的安全行为为从原始多轮轨迹中恢复分布式安全证据提供监督。这种设计使 ReDiR 能够直接在生成过程中整合跨轮安全信息，而无需依赖独立的动作级安全模块。我们在三个模型系列和八个留出工具领域的两个智能体安全基准上评估了 ReDiR。ReDiR 将攻击成功率降低到 8% 以下，可迁移到未见过的工具领域，并以较低的计算开销保持了良性保真度。

## Abstract
Tool-using LLM agents extend security risks beyond generated text to actions that affect external systems. Under multi-turn decomposition attacks, a harmful objective can be distributed across individually plausible requests and tool calls, becoming apparent only from the accumulated trajectory. Existing defenses either rely on auxiliary online reasoning to recover long-horizon security evidence or assess actions after generation, often incurring additional inference cost or depending on runtime-specific action representations.   We propose \emph{Reassembling Distributed Risk} (ReDiR), a generation-time defense that conditions action generation on trajectory-level security evidence. Before each action, ReDiR compresses the current trajectory into a compact latent safety representation and injects it into the frozen base model. The representation is learned through same-model, cross-view supervision, where safe behavior from an explicit task view provides supervision for recovering distributed safety evidence from the original multi-turn trajectory. This design enables ReDiR to integrate cross-turn security information directly within the generation process without relying on a separate action-level safety module. We evaluate ReDiR on two agent-safety benchmarks across three model families and eight held-out tool domains. ReDiR reduces attack success rates to below 8\%, transfers to unseen tool domains, and preserves benign fidelity with low computational overhead.

### 论文总结：重组分布式风险（ReDiR）

#### 1. 核心问题与整体含义（研究动机和背景）
随着 LLM 智能体（Agent）在外部系统（如文件系统、数据库）中的广泛应用，安全风险从单纯的文本输出扩展到了具有实际影响的“动作”。论文关注的是**多轮分解攻击（Multi-Turn Decomposition Attacks）**：攻击者将一个有害目标拆分为多个看似无害的步骤。例如，第一步请求创建删除脚本，第二步请求定位根目录，第三步请求执行。
*   **现有防御的局限：** 现有的防御手段要么依赖昂贵的在线推理（如辅助模型实时判断），要么在动作生成后进行检查（依赖特定运行时的表示，难以跨工具迁移）。
*   **核心动机：** 如何在不增加显著推理开销的前提下，让模型在生成动作时就能感知到分散在历史轨迹中的潜在风险。

#### 2. 论文提出的方法论：ReDiR
ReDiR 的核心思想是将多轮交互轨迹压缩为**潜在安全表示（Latent Safety Representation）**，并将其注入到冻结的基座模型中，直接引导安全动作的生成。

*   **核心步骤：**
    1.  **离线监督构建（Offline Supervision Construction）：** 采用“同模型、跨视图”策略。将多轮攻击轨迹折叠为一个显式的单轮任务视图，让基座模型在该视图下生成安全的动作目标（如 `FINISH` 动作）。这样可以获得与模型自身行为对齐的高质量安全标签。
    2.  **轨迹条件安全训练（Trajectory-Conditioned Training）：** 训练一个安全编码器（基于 LoRA 适配的相同模型骨干）。它通过 $K$ 个可学习的潜在查询（Latent Queries）聚合轨迹证据。
    3.  **潜在注入与生成（Latent-Guided Generation）：** 在推理时，编码器将当前轨迹转化为潜在向量，注入到基座模型的嵌入层之后。基座模型在这些向量的引导下生成动作。
*   **关键技术细节：**
    *   **路由监督：** 仅对需要纠正的动作位置进行监督，保留模型原有的良性行为。
    *   **良性保留损失（Benign Retention Loss）：** 使用 KL 散度约束，确保模型在处理正常任务时不会出现过度防御（拒绝服务）。

#### 6. 论文的主要结论与发现
*   **显著降低风险：** ReDiR 将多轮攻击的成功率（ASR）降至 **8% 以下**（部分模型甚至达到 0%）。
*   **强泛化性：** 安全性可以从单一领域（如文件系统）完美迁移到其他完全不同的工具领域（如 Reddit、GitLab）。
*   **高保真度：** 在良性任务上的误报率（FPR）保持在 **0%**，证明了其不会损害智能体的正常功能。
*   **高效性：** 相比于需要额外运行一个安全判断模型的方案，ReDiR 的内存占用极低（仅需几 MB 存储 LoRA 参数）。

#### 7. 优点
*   **生成时干预：** 不同于“生成后检查”，ReDiR 在动作产生前就改变了模型的隐藏状态，更具主动性。
*   **架构优雅：** 复用基座模型的骨干网络，避免了维护多个大模型的显存压力。
*   **独立于运行时：** 不依赖特定的工具 Schema 或动作格式，具有极强的通用性。
*   **同模型监督：** 巧妙利用模型自身的“显式视图”作为教师，解决了多轮安全数据标注难的问题。

#### 8. 不足与局限
*   **白盒依赖：** 该方法需要访问模型的嵌入层和隐藏状态，因此不适用于仅提供 API 访问的闭源模型（如 GPT-4 官方 API）。
*   **训练数据构建复杂：** 虽然是自动化的，但离线构建“折叠视图”和审计安全目标的过程仍需精心设计。
*   **潜在的对抗风险：** 尽管测试了历史稀释攻击，但更高级的针对潜在表示空间的对抗扰动（Adversarial Perturbations）尚未被深入探讨。
