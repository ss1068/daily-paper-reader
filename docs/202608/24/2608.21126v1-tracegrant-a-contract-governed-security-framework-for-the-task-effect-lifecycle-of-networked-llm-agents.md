## 摘要
联网大语言模型 (LLM) 智能体从电子邮件、云存储、日历、交易平台和 Web 服务中检索信息，以完成产生持久外部效应的多步任务。合法执行所需的相同内容也可能包含间接提示注入，从而重定向工具使用、篡改敏感参数或破坏任务完成。现有的防御措施主要限制不可信内容或单个工具调用，导致用户意图、运行时证据、实现的效应以及任务完成之间的连接不足。我们提出了 TraceGrant，这是一个通过显式合约 (Contract) 治理联网 LLM 智能体任务-效应生命周期的安全框架。在执行前，TraceGrant 根据受信任的用户请求建立任务-效应边界。在执行期间，准入的证据只能实例化合约中已建立的权限。在执行后，根据实际的工具结果验证任务完成情况。在固定基准设置下的 949 个 AgentDojo 和 400 个 Agent Security Bench 攻击案例中，TraceGrant 记录了零攻击成功率，同时在攻击率分别为 77.32% 和 83.00% 的情况下保持了效用。我们还通过白盒防御感知攻击、合约质量分析、阶段消融实验、针对性压力测试和运行时开销测量对 TraceGrant 进行了进一步评估。结果表明，TraceGrant 提供了一个统一的治理层，连接了受信任的用户意图、运行时证据、具体的工具执行和经过验证的任务完成。

## Abstract
Networked large language model (LLM) agents retrieve information from email, cloud storage, calendars, transaction platforms, and Web services to complete multistep tasks that produce persistent external effects. The same content needed for legitimate execution may also contain indirect prompt injections that redirect tool use, alter sensitive arguments, or disrupt task completion. Existing defenses mainly constrain untrusted content or individual tool calls, leaving user intent, runtime evidence, realized effects, and task completion insufficiently connected. We present TraceGrant, a security framework that governs the task-effect lifecycle of networked LLM agents through an explicit Contract. Before execution, TraceGrant establishes a task-effect boundary from the trusted user request. During execution, admitted evidence can instantiate only authority already established by the Contract. After execution, task completion is verified against actual tool results. Across 949 AgentDojo and 400 Agent Security Bench attack cases under fixed benchmark settings, TraceGrant recorded no attack successes while retaining utility under attack rates of 77.32% and 83.00%, respectively. We further evaluate TraceGrant through white-box defense-aware attacks, Contract quality analysis, stage ablations, targeted stress tests, and runtime overhead measurements. The results show that TraceGrant provides a unified governance layer that connects trusted user intent, runtime evidence, concrete tool execution, and verified task completion.

### TraceGrant：联网 LLM 智能体任务-效应生命周期的合约治理安全框架论文总结

#### 1. 核心问题与整体含义（研究动机和背景）
随着联网大语言模型（LLM）智能体能力的增强，它们能够通过工具接口访问电子邮件、云存储、支付系统等外部服务。然而，这种能力也带来了严重的**间接提示注入（Indirect Prompt Injection, IPI）**风险。攻击者可以通过外部内容（如恶意邮件或网页）诱导智能体执行非授权操作。
**核心矛盾**在于：合法任务往往需要读取不可信的运行时内容来确定后续操作的参数（如从邮件中获取收件人），但这些内容可能被篡改。现有的防御机制（如内容过滤或单次工具授权）未能将用户意图、运行时证据、实际执行效应和任务完成状态系统性地连接起来。本文旨在建立一个覆盖任务全生命周期的安全治理框架。

#### 2. 方法论：核心思想与关键技术
TraceGrant 的核心思想是**“将运行时数据视为现有授权的证据，而非新授权的来源”**。它通过一个显式的 **POEC 合约**来治理任务：

*   **POEC 合约结构**：
    *   **Permission (MAY)**：界定允许的工具、目标范围、参数约束和调用预算。
    *   **Obligation (MUST)**：组织任务步骤的依赖关系（证据获取、外部效应、输出要求）。
    *   **Evidence (BIND)**：定义动态参数的合法来源、类型及推导规则，确保参数必须有据可查。
    *   **Completion (VERIFY)**：规定任务完成的观测条件。
*   **三个关键阶段**：
    1.  **执行前（合约建立）**：语义合约编译器将用户请求转化为 POEC 合约，并通过确定性静态分析验证合约的安全性。
    2.  **执行中（运行时授权）**：使用“义务账本”（Obligation Ledger）跟踪状态。只有满足 BIND 规则的证据才能实例化参数。PDP（策略决策点）发放一次性“效应证书”（Effect Certificate）供 PEP（策略执行点）执行。
    3.  **执行后（验证与关闭）**：生成“效应收据”（Effect Receipt）验证实际执行结果。只有所有硬性义务（Hard Obligations）都被验证后，“最终答案门控”才允许宣告任务完成。

    *   **Agent Security Bench (ASB)**：涵盖金融、法律、医疗等 10 个领域，共 400 个攻击案例。
*   **对比方法（Baselines）**：

*   **测试模型**：主要使用 DeepSeek-V4-Flash，并交叉验证了 Gemini 3.6 Flash、Qwen3.7-Plus 和 GLM-5.2。

#### 5. 实验数量与充分性
*   **实验规模**：总计测试了超过 1349 个攻击案例，每个案例独立运行 3 次，产生了数千条执行轨迹。

    *   **多维度评估**：除了基础的攻击成功率（ASR）和任务成功率（TSR），还进行了阶段消融实验、合约质量分析、针对性压力测试（针对运行时授权和完成完整性）。
    *   **白盒攻击分析**：设计了 100 个防御感知型攻击案例，模拟攻击者已知晓 TraceGrant 机制的情况，测试其防御边界。
    *   **客观性**：使用了统一的基准测试环境和官方评估器，对比了多种主流防御方案，实验设计较为客观、全面。

#### 6. 主要结论与发现
*   **极高的安全性**：在 AgentDojo 和 ASB 的固定基准设置下，TraceGrant 实现了 **0% 的攻击成功率（ASR）**。
*   **效用保持**：在遭受攻击的情况下，TraceGrant 仍能保持较高的任务效用（UUA 分别为 77.32% 和 83.00%），显著优于其他防御方案。
*   **跨模型稳定性**：安全性能在不同基础模型上表现一致，证明了框架的稳健性。
*   **生命周期治理的必要性**：消融实验证明，仅靠执行前合约或仅靠运行时检查是不够的，必须通过收据验证和门控机制连接全过程。

#### 7. 优点（亮点）
*   **全生命周期覆盖**：首次将“合约”概念引入智能体安全，实现了从意图到结果的闭环治理。
*   **证据绑定机制**：通过 BIND 规则强制要求动态参数必须来源于受信任的证据，有效阻断了通过注入内容篡改关键参数（如转账账号）的路径。
*   **确定性执行**：将 LLM 的模糊推理与确定性的策略强制执行（PDP/PEP）相结合，增强了系统的可预测性。

#### 8. 不足与局限
*   **语义毒化风险**：如果证据来源本身是合法的但内容被毒化（例如合法的账单文件内被填入了错误的收款人），TraceGrant 虽能保证来源正确，但无法完全识别业务逻辑上的欺骗。
*   **运行时开销**：引入了额外的 LLM 调用和状态维护，导致延迟和 Token 成本上升（约 30%-40% 的增幅）。
*   **合约覆盖完整性**：白盒测试显示，如果合约编译器未能覆盖某些可选的权限参数，攻击者仍有利用空间。
*   **复杂任务支持**：目前主要针对结构化较强的任务，对于长周期、多智能体协作或高度异步的任务，合约的复杂度和维护难度会大幅增加。
