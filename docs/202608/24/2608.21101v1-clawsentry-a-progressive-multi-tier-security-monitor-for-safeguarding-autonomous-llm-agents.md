## 摘要
随着大语言模型（LLM）智能体从对话转向执行代码、读取本地文件以及编排外部工具，被恶意第三方技能劫持的单个智能体可能会导致数据外泄、权限提升或级联破坏。我们认为智能体风险是渐进式的：它可能在智能体控制循环的四个位点介入——技能准入、调用时意图、执行时效果和动作后后果；而一个被拒绝的危险目标可能会跨越表现形式、工具或轮次重新出现。现有的防护措施通常局限于单一生命周期边界或单次调用。基于这一威胁模型，我们提出了 ClawSentry，这是一个开源且与框架无关的智能体运行时安全监管网关。在技能包执行之前，首次使用技能包审查（FSPR）会在确定性证据基准下对其进行审计，并将未解决的案例升级到受限的只读智能体审查（位点 A）。在运行时，一个三层渐进式决策引擎——确定性 L1 层、以规则为锚点的 L2 语义审查器和只读的 L3 证据寻求智能体——仅针对残留歧义进行上下文审查，同时会话级反绕过机制可识别工具切换和改写后的重试（位点 B-C）；动作后路径将高严重性证据非追溯性地反馈到后续审查中（位点 D）。智能体治理协议（AHP）抽象层在不修改智能体内部结构的情况下，将统一策略应用于 Codex、Claude Code、Kimi CLI 和 Gemini CLI。在 SkillInject 任务中，使用 Codex/GPT-5.4 时，上下文攻击成功率（ASR）从 39.55% 下降到 2.61%，而上下文任务成功率（TSR）仅从 83.78% 变动至 83.05%。在完整 SkillsSafety 基准测试的五个工作智能体中，ClawSentry 将 ASR 从未受保护时的 33.5-49.7% 限制在 9.09-15.03%，且清洁技能的总 TSR 保持在 98.7%。

## Abstract
As large language model (LLM) agents move from conversation to executing code, reading local files, and orchestrating external tools, a single agent hijacked by a malicious third-party skill can cause data exfiltration, privilege escalation, or cascading compromise. We argue that agentic risk is progressive: it can enter at four loci of the agent control loop--skill admission, invocation-time intent, execution-time effect, and post-action consequence--while a denied dangerous objective can reappear across surface forms, tools, or turns; existing safeguards are typically local to one lifecycle boundary or one call. Guided by this threat model, we present ClawSentry, an open-source, framework-agnostic security supervision gateway for agent runtimes. Before a skill package is ever executed, First-use Skill Package Review (FSPR) audits it under a deterministic evidence floor, escalating unresolved cases to bounded read-only agentic review (locus A). At runtime, a three-tier progressive decision engine--a deterministic L1 layer, a rule-anchored L2 semantic reviewer, and a read-only L3 evidence-seeking agent--spends contextual review only on the residual ambiguity, while a session-level anti-bypass mechanism recognizes tool-switching and rephrased retries (loci B--C); a post-action path feeds high-severity evidence non-retroactively into later review (locus D). An Agent Harness Protocol (AHP) abstraction applies one policy across Codex, Claude Code, Kimi CLI, and Gemini CLI without modifying agent internals. On SkillInject with Codex/GPT-5.4, contextual ASR falls from 39.55% to 2.61% while contextual TSR moves only from 83.78% to 83.05%. Across five Work Agents on the full SkillsSafety benchmark, ClawSentry confines ASR to 9.09--15.03% from 33.5--49.7% unprotected, and aggregate TSR on clean skills remains 98.7%.

随着大语言模型（LLM）智能体从简单的对话转向自主执行代码、操作文件系统和调用外部工具，其面临的安全威胁也从“提示词注入”演变为“系统级破坏”。论文指出，智能体风险具有**渐进性（Progressive）**，可能发生在生命周期的四个位点：技能准入（A）、调用意图（B）、执行效果（C）和动作后果（D）。
**研究动机：** 现有的防御方案通常只针对单一阶段或单次调用，无法应对攻击者通过改写参数、切换工具或跨回合重试来绕过防御的手段。因此，需要一个全生命周期、跨框架且具备“记忆”能力的安全网关。

### 2. 方法论
论文提出了 **ClawSentry**，一个与框架无关的渐进式多层安全监控网关，核心组件包括：
*   **智能体治理协议 (AHP)：** 一种抽象层，通过统一的事件模式（CanonicalEvent）将不同智能体框架（如 Codex, Claude Code）的底层操作标准化，实现一套安全策略应用于多个平台。
*   **首用技能包审查 (FSPR)：** 在第三方技能包首次运行前进行静态审计（确定性规则）和受限的只读智能体审查，从源头拦截恶意插件。
*   **三层渐进式决策引擎：**
    *   **L1 (确定性层)：** 使用高效规则和短路逻辑处理清晰的违规或安全操作，无需调用模型。
    *   **L2 (语义分析层)：** 针对模糊操作，利用轻量级模型结合 25 种攻击模式（参考 OWASP）进行意图识别。
    *   **L3 (智能体分析层)：** 针对高度复杂的残留歧义，调用具备只读工具权限的智能体进行深度上下文审计。
*   **会话级反绕过机制：** 记录被拒绝的操作指纹，识别并拦截通过改写、拆分任务或更换工具进行的重复攻击。
*   **只读约束：** 所有的审查器（Reviewer）均被设计为只读，不具备执行、写入或联网权限，防止审查器本身被劫持。

*   **审查模型：** 默认使用 `gemini-3.5-flash` 作为安全审查器，同时也测试了 `minimax-m2.7`、`deepseek-v4-pro` 和 `glm-5.1` 等模型作为审查器的表现。

### 5. 实验数量与充分性
*   **实验规模：** 进行了超过 300 组 provider-case 执行，涵盖了 5 种不同的工作智能体。

*   **多样性：** 进行了审查器替换实验，证明了防御效果源于网关架构而非特定模型的性能。

### 6. 主要结论与发现
*   **显著提升安全性：** 在 SkillsSafety 基准下，将 ASR 从 33.5%-49.7% 降低至 9.09%-15.03%。在 SkillInject 中，ASR 最低降至 2.61%。
*   **保持高可用性：** 在处理清洁（无毒）技能时，任务成功率（TSR）保持在 98.7%，证明防御机制极少误伤正常工作。
*   **准入审查至关重要：** 实验发现，一旦恶意技能包进入上下文，其对任务成功率的破坏在防御介入前就已经发生，因此“预审”比“运行时拦截”更有效。
*   **成本可控：** 渐进式漏斗机制使得只有极少数复杂案例需要高昂的模型审查费用。

### 7. 优点
*   **框架无关性：** AHP 协议的设计使其能够轻松适配各种新兴的智能体框架。
*   **全生命周期覆盖：** 填补了现有防御在“技能准入”和“跨回合绕过识别”上的空白。
*   **防御深度与效率平衡：** L1-L3 的分层设计在保证安全深度的同时，极大地优化了延迟和成本。
*   **开源贡献：** 提供了开源实现和版本化的 YAML 攻击模式库。

### 8. 不足与局限
*   **非自适应攻击：** 实验主要针对静态基准测试，尚未充分评估攻击者在完全知晓 ClawSentry 策略后的“针对性对抗”表现。
*   **L3 延迟：** 尽管 L3 调用频率低，但对于需要实时响应的场景，多轮智能体审计仍可能带来可感知的延迟。
*   **无人值守偏差：** 在实验中，所有“延迟（Defer）”决策都被视为“拦截（Block）”，这在实际应用中可能需要人工介入才能达到最佳的 TSR。
*   **覆盖范围：** 目前主要针对代码执行类智能体，对于视觉/GUI 智能体或多智能体协作（MAS）的复杂通信安全涉及较少。
