## 摘要
集成外部资源的大语言模型（LLM）智能体获得了处理复杂任务的能力，但统一的自然语言上下文通道使其容易受到注入攻击：不可信的外部数据可能在 LLM 推理过程中被动态解析为行为引导指令，从而颠覆智能体的决策。现有的防御措施侧重于输入/输出层面的恶意内容静态检测或隔离，对于检测模型推理过程中出现的此类动态诱导仍显不足。我们提出了 Attnlocate，这是一个运行时框架，用于细粒度定位真正影响工具调用决策的上下文片段（即行为引导指令）。Attnlocate 将此定位问题建模为目标检测任务，旨在检测注意力矩阵中由行为引导指令诱发的独特激活痕迹。具体而言，我们设计了一种多头、多层注意力聚合方案，以构建专为目标检测定制的词元（token）级特征空间。随后，部署一个配备无锚点（anchor-free）检测头的一维 U-Net 来检测这些片段。最后，根据检测到的行为引导片段来源提供者的权限，Attnlocate 动态判定恶意的调用尝试。我们在来自五个 LLM 家族的十种智能体配置上评估了 Attnlocate，涵盖了涉及间接提示注入和工具投毒的场景。Attnlocate 实现了 0.743 的平均交并比（mIoU）、0.956 的平均 AUROC，以及在 0.067 的假阳性率下达到 0.934 的真阳性率。它还能有效地迁移到未见过的模型，并支持无需重新训练的权限策略调整。

## Abstract
LLM agents integrated with external resources gain complex task capabilities, yet the unified natural-language context channel makes them vulnerable to injection attacks: untrusted external data may be dynamically parsed as behavior-guiding instructions during LLM inference, thereby subverting the agent's decision. Existing defenses focus on static detection or isolation of malicious content at the input/output level, remains insufficient for detecting such dynamic inducements that arise during model reasoning. We propose Attnlocate, a runtime framework for fine-grained localization of context spans that genuinely influence tool-calling decisions, i.e., behavior-guiding instructions. Attnlocate casts this localization problem as an object detection task, aiming to detect the distinctive activation traces induced by behavior-guiding instructions within the attention matrix. Specifically, we design a multi-head, multi-layer attention aggregation scheme to construct a token-level feature space tailored for object detection. Then, a 1-D U-Net equipped with an anchor-free detection head is deployed to detect these spans. Finally, based on the authority of the provider from which the detected behavior-guiding spans originate, Attnlocate dynamically adjudicates malicious invocation attempts. We evaluate Attnlocate across ten agent configurations from five LLM families, covering scenarios involving indirect prompt injection and tool poisoning. Attnlocate achieves a mean IoU of 0.743, an average AUROC of 0.956, and a 0.934 true-positive rate at 0.067 false-positive rate. It also transfers effectively across unseen models and supports authority policy adaptation without retraining.

### 1. 核心问题与整体含义（研究动机和背景）
*   **核心问题**：LLM 智能体（Agent）通常将用户指令、系统提示和外部资源（如工具输出、网页内容）混合在同一个自然语言上下文中。这种“指令与数据不分”的架构导致了**注入攻击**（如间接提示注入和工具投毒）：攻击者可以将恶意指令伪装成普通数据，诱导智能体执行未经授权的操作（如读取敏感文件）。
*   **研究背景**：现有的防御手段（如静态扫描或沙箱隔离）往往只能识别明显的恶意内容，或者简单地阻断行为，却无法在推理过程中精准识别出**到底是哪一段上下文**真正引导了智能体的决策。

### 2. 方法论：AttnLocate 框架
AttnLocate 的核心思想是将“识别引导决策的指令”转化为一个**一维目标检测任务**，通过分析 LLM 内部的注意力矩阵（Attention Matrix）来定位攻击。

*   **注意力聚合（Attention Aggregation）**：
    *   **多头聚合**：对各层的多头注意力进行平均。
    *   **高斯层加权**：使用以中高层（约 2/3 深度处）为中心的高斯分布对不同层进行加权，因为这些层通常包含更多任务相关的推理信息。
    *   **决策条件切片**：仅提取与最终工具调用决策（Decision）相关的注意力信号。
*   **指令定位（Instruction Localization）**：
    *   **1-D U-Net 骨干网络**：将提取的词元级特征输入 U-Net，通过编码器-解码器结构捕捉长距离依赖并恢复词元级分辨率。
    *   **无锚点检测头（Anchor-free Head）**：借鉴 FCOS 算法，预测每个位置的“目标存在概率（Objectness）”、“边界偏移量（Offsets）”和“中心度（Centerness）”，从而精确定位变长的指令片段。
*   **汇点感知正则化（Sink-Aware Regularization）**：针对 LLM 中常见的“注意力汇点（Attention Sink）”噪声（即某些无意义词元获得极高注意力），设计了专门的损失函数权重，强制模型区分真正的指令和背景噪声。
*   **权限判定（Adjudication）**：定位到指令片段后，解析其来源（如来自用户还是外部工具），并根据预设的权限策略（如外部工具无权引导敏感操作）判定该行为是否违规。

### 7. 优点
*   **细粒度定位**：不仅能发现攻击，还能精确指出是哪一段文字导致了违规决策，具有极高的可解释性。
*   **运行时监控**：在推理阶段动态工作，能够防御静态检测无法发现的隐蔽注入。
*   **强迁移性**：检测模型对不同架构的 LLM 具有良好的泛化能力，降低了部署成本。
*   **策略灵活**：将“定位”与“判定”解耦，允许管理员根据业务需求灵活配置权限策略。

### 8. 不足与局限
*   **白盒依赖**：需要获取 LLM 的内部注意力矩阵，这在闭源 API（如 GPT-4）场景下无法直接应用。
*   **长文本挑战**：在极长文本（如海量文档检索）中，注意力信号会被稀释，导致检测精度下降。
*   **计算开销**：虽然 U-Net 很轻量，但提取和处理大规模注意力矩阵仍会带来一定的推理延迟。
*   **对抗性风险**：攻击者可能会针对注意力机制设计专门的“注意力规避”攻击，试图隐藏其指令的激活痕迹。
