ABSTRACT 

Security evaluation of learning-based systems requires more than just testing the system against a fixed collection of attacks. It requires adaptive mechanisms that can efficiently discover sets of inputs that induce model failure. We introduce AT-LAS (Adaptive Trust-Regions for Latent Adversarial Searches), which is a query-based framework that discovers adversarial input sets for black-box learning sys-tems. ATLAS casts attack generation as an active learning level set estimation problem then combines calibrated approximations with a local-global sampling architecture to find regions of the input space that contain adversarial examples. Once discovered, ATLAS is designed to sample points within these adversarial regions to build adversarial sets that accurately represent the state of robustness of the target model. When applied on toy experiments, we find that ATLAS is able to recover more of the adversarial region under a limited query budget than does previous work. When applied to standard and adversarially trained MNIST, CI-FAR, and ImageNet model targets, ATLAS produces better representative attacks than other query-based black-box attacks (NES, SignHunter, BayesOpt). ATLAS represents an automated red-teaming framework that can be used for both analyz-ing the robustness of learning-based systems under development and continuous auditing to see how the robustness of a system changes over time. 

1 INTRODUCTION 

As more learning-based systems get deployed in safety critical settings (Eykholt et al., 2018; Chou et al., 2021), robust evaluation requires more than testing against a fixed collection of previously known attacks(Athalye et al., 2018; Croce and Hein, 2020). An evaluator must be able to adaptively discover diverse inputs that induce failure, especially for complex targets whose failure mechanisms are unknown (Nasr et al., 2025; Bahati et al., 2021). Existing black-box adversarial attacks are de-signed to discover one/few successful failures. However, in our problem, our goal is to identify a set of adversarial inputs that produces failures for a specified target system. Rather than optimizing for a single successful adversarial example, this formulation seeks to produce a wide-spread adversarial set that can be used to audit where and how a learning-based system fails (Figure 1). The challenge comes from the input space being high-dimensional, making exhaustive search infeasible, and po-tentially having input adversarial regions occupy only a small fraction of the overall search space, making unguided exploration unlikely to discover them. Therefore, we introduce ATLAS, an active-learning framework for generating adversarial sets in high-dimensional spaces. One of the key innovations is that it re-formulates adversarial discovery as a region-discovery problem and combines tools from level-set estimation, Bayesian optimization, and adversarial generation to build these sets . Because existing approaches (Ngo et al., 2026; Eriks-son et al., 2019; Deglurkar et al., 2026; Paccagnan et al., 2023) are not enough to solve this problem - these approaches aren’t designed to generate diverse adversarial sets - ATLAS builds upon previ-ous work and uses calibrated model predictions combined with a dual sampling mechanism to build both an adversarial classifier and the associated adversarial dataset. To evaluate ATLAS, we first use non-convex benchmark functions helps us analyze ATLAS’ ability to recover sparse and geo-metrically complex adversarial sets in toy problems. After this, we apply ATLAS on several image classification models. When compared against popular optimization-based methods, we find that not only is ATLAS able to recover sets with more empirical coverage of the adversarial region, but it is also able to curate attacks with a success rate that is on par or better than the baselines. 

Our contributions are : (1) framing adversarial generation as an active level-set estimation problem rather than an optimization problem, and showing that optimization-based attacks recover less of the adversarial set even when all of their queries are retained; (2) calibrating the surrogate’s predictions with a residual model trained over the entire input space, in contrast to prior work that calibrates the sample-selection score; (3) designing a saturation trust region and acquisition that recover the interior of the adversarial set rather than only its boundary; and (4) evaluating on non-convex bench-marks with known ground-truth level sets up to 100D, and on standard and adversarially trained MNIST, CIFAR-10, and ImageNet classifiers, with ablations isolating (2) and (3). 

2 RELATED WORKS 

There are certain categories of methods that generate image attacks: (a) Methods that use gradient-based approaches to craft adversarial inputs (Goodfellow et al., 2014; Eykholt et al., 2018; Papernot et al., 2017; Kurakin et al., 2018; Carlini and Wagner, 2017; Ilyas et al., 2019; Athalye et al., 2018; Kurakin et al., 2016; Croce and Hein, 2020), (b) methods that use generative models to generate adversarial images (Xiao et al., 2018; Jandial et al., 2019; Song et al., 2018), (Poursaeed et al., 2018; Xu and Zhai, 2023), and (c) query-based methods that finds attacks to black box systems. In the latter, there exist Bayesian Optimization based approaches (Shukla et al., 2019; Cheng et al., 2024; Zhang et al., 2024; Ru et al., 2019) and generic querying methods like SquareAttack (An-driushchenko et al., 2020), SignHunter (Al-Dujaili and O’Reilly, 2020), and NES (Ilyas et al., 2018). Most notably, BayesOpt (Ru et al., 2019) is a well known method that is most similar to ours. In this work, they aim to find L∞ based perturbation using similar adaptive sampling mechanisms as we do; however, they get around the curse of dimensionality by decomposing the input space into lower dimensional subspaces and assigning a local model to represent the adversarial objective in that lower-dimensional space. This is complementary to our method. In ATLAS, our input space is decomposed into local regions of the same dimension, while BayesOpt decomposes its search space into manifolds of lower dimensions. Furthermore, their method is designed to optimize an adversar-ial objective to find one specific attack. Our framework is designed to learn an adversarial mapping globally; thereby learning entire sets of adversarial examples that exists for a target system. Because of the differing aims, our adaptive sampling mechanisms are geared towards minimizing model error vs. generic adversarial maximization. Other approaches leverage LM-evolutionary methods (Nasr et al., 2025), (Zhan et al., 2025), and generic try-and-check methods (Gibson et al., 2024) as well.

itself. However, trying to sample the interior of S is not trivial. Interior candidates can only be cho-sen from the surrogate’s own prediction of where S lies. This prediction is often wrong and causes queries to land outside of S or in already highly sampled regions the model knows well. While prior work (Deglurkar et al., 2026) attempt to calibrate where samples are selected using calibrated ac-quisition functions, these functions combine prediction and uncertainty on an arbitrary scale, which makes it both harder to calibrate and redundant to do so: the calibration must be repeated for every acquisition function, and none of it corrects the underlying model. Our key idea is therefore to cali-brate the model’s prediction directly, using a residual model trained on the main model’s error over the entire input space. A single correction then propagates to every acquisition built on that model. This lets us define two complementary selection rankings over a shared calibrated surrogate: one preferring candidates near the zero level set ( boundary ), which improves classification of the adver-sarial region, and one preferring candidates predicted to lie inside S (saturation ), which curates the adversarial set.

Sampling deep inside the super level set sacrifices average dispersion, since samples there are closer together than samples along the boundary. As ATLAS goes deep into the super level set to produce a set with more representative margin spread, its set’s coverage decreases on average, which is why our dispersion spread is somewhat lower than our baselines. Although it loses coverage, it gains coverage of adversarial scores that would not otherwise be recoverable with the other baselines or uniform sampling. At 50D and 100D, ATLAS recovers adversarial scores that are higher than every sample in the super level test set.

7 CONCLUSION 

In conclusion, this paper presents ATLAS, a framework that reformulates adversarial discovery as a region-recovery problem, leverages active learning and level-set estimation for this problem, and introduces new mechanisms that are specifically required for adversarial-set and adversarial classification construction. In this work, we find that ATLAS can construct more diverse adversarial sets, which provides a useful foundation for building automated red-teaming tools. There is still some variance in performance between function landscapes. Sampling deep inside the super level set sacrifices average dispersion, since samples there are closer together than samples along the boundary. C IMPLEMENTATION SPEED UP 

In large dimensions, most of ATLAS’s runtime comes from training a new global model on samples and choosing the new TR centers using limited memory BFGS with bound constraints (L-BFGS-B) and warm starts. To address the latter, we ultimately use analytic gradients during optimization 1

and parallelize specific calculations. Both mechanisms give us tremendous speed ups, which are most beneficial after the model starts acquiring a large amount of samples during its run. The timing metrics shown are runtimes when using CPU. Depending on the choice of model and learning algorithm, further speeds up can be realized by using GPU resources. 

D IMAGE EXPERIMENT DETAILS 

The models chosen are ResNet50 (He et al., 2016) for CIFAR’s and ImageNet’s standard target with 93.65% and 76.13% accuracy respectively, WRN-28-10 adversarially trained ( AT ) with DDPM (Re-buffi et al., 2021) with 60.75% accuracy for CIFAR’s AT target, ResNet50 AT on Linf perturbations (Salman et al., 2020) with 54.53% accuracy for ImageNet’s AT target, and a pre-trained LeNet5 from (Singh, 2019a) with 99% accuracy. We use a conditional DCGAN (Radford et al., 2015) and BIGGAN and BIGGAN-256 (Brock et al., 2018) for our image generators for MNIST, CIFAR, and ImageNet respectively. BIGGAN and the conditional DCGAN was retrained from scratch using (Singh, 2019b) implementation to take in 32 dimensions and a source class, while the implementa-tion and trained weights for BIGGAN-256 comes from StudioGAN(Kang et al., 2023). BayesOpt is run in its native early-stopping configuration, while NES and SignHunter is ran until the full budget generating its version of an adversarial set. We tried to run BayesOpt similarly; however, we found it to be more computationally infeasible to do. We therefore report ASR and query-to-success for BayesOpt, and omit the dispersion statistics, which require the run-to-budget super-level sets. Full analysis of ATLAS, NES, SignHunter, BayesOpt, and uniform sampling is in Table 9. 

E INTERPRETING ATLAS I MAGE RESULTS 

For each experiment, we ask: (1) whether the generated adversarial sets contain images with visual semantics that are common under the source class with little to no features of the target class or (2) whether there are any particular characteristics or patterns that emerge from all images (realistic or not) that could indicate which features the model’s boundary region for the target class is built on. The generated adversarial sets for both MNIST and CIFAR represent the former. These are interest-ing failure cases because it represents manifold-constrained adversarial images which could present as benign or containing imperceptible perturbations but that gets misclassified by the model (most similar to L∞ attacks). On the other hand, the generated adversarial sets for ImageNet represent more of the latter. The latter is important analysis because it tells us what features the models may hone in on for a particular classification and tells us what features push the model’s decision bound-ary from one class to another. Take as example the “stingray → great white shark (g.w. shark)” row in the “Imagenet” section in Figure 5. All images contain a birds-eye view of the ocean with sightings of a stingray in the water which are all reasonable images for the stingray class. Because these images are being classified as a great white shark, this tells us that the model is most likely to key in on the ocean (a shark’s environment) rather than a shark’s features for its classification.

F SECURITY AUDIT SUMMARY 

We interpret ATLAS as a model-level security auditing tool and summarize our audit findings using the NIST AI Risk Management Framework (AI RMF) (AI, 2023) and the MITRE ATLAS threat framework (MITRE Corporation, 2021). The evaluation models an attacker who can query a classi-18 Published as a conference paper at ICLR 2027 fier but does not require access to its weights or training infrastructure. In MITRE ATLAS terminol-ogy, the procedure generates adversarial data (AML.T0043) to evade an AI model (AML.T0015). The potential consequences of successful misclassification are context dependent and should be as-sessed separately. 

MAP. We identify targeted adversarial attacks that represent security risks using a chosen image generator. We characterize “failure regions” within this generator’s input latent space that contain latents that map to images containing the visual features of a specified source class but for which gets misclassified by the target model. 

MEASURE. ATLAS measures the accessibility and size of each discovered failure region under a fixed query budget (see Table 4). Across all reported settings, ATLAS recovered nonempty sets, including against adversarially trained CIFAR-10 and ImageNet models, indicating that the adver-sarial training process for each adversarially trained model did not eliminate the existence of targeted failure regions. 

MANAGE. The resulting adversarial sets point to model vulnerabilities that are fairly accessible for outside users. The examples within these sets should be used to guide additional robustness evalua-tion, adversarial training, or the creation of monitoring and security filters as potential defenses. 

GOVERN. Finally, the recovered adversarial sets, ATLAS’s trained surrogate model, and quantita-tive measurements, all encodes the state of security for each subject target, while the threat model, query budget, source-target pairs, and experimental settings provide documentation for how to re-peat this security analysis after the model has been robustified with better security defenses. Each of these resulting audit artifacts should be used to inform deployment decisions. 

ETHICAL CONSIDERATIONS 

This system, while designed for developers to robustify their own systems, may be leveraged by outside actors to attack other systems they do not own. While this may be the case, to mitigate the potential damage of such cases, future work includes analyzing the limitations of this system, which includes finding the functional characteristics (defenses) for which similar algorithms are unable to efficiently map inputs their associated adversarial scores. Other possible mitigations include limiting query access to outside systems.
