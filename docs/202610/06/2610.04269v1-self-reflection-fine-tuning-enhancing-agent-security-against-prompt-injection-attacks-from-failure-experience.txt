# ABSTRACT 

Large language model (LLM) agents are increasingly deployed in tool-augmented environments, but their reliance on external inputs makes them highly vulnera-ble to prompt injection attacks that can hijack task objectives. Existing safety alignment methods rely on static expert trajectories or preference optimization, limiting their ability to generalize to adaptive attack patterns. In this work, we propose Self-Reflection Fine-Tuning (SRFT), a training framework that enables agents to improve robustness by learning from their own failure experiences un-der adversarial conditions. Instead of passively imitating expert behaviors, SRFT exposes the agent to compromised trajectories constructed via injected attacks, and leverages an expert model to generate structured self-reflection reasoning that contrasts unsafe and optimal actions. This reflective supervision teaches the agent to identify malicious instructions, reason about their consequences, and maintain alignment with the original user intent. We instantiate this framework in SR-Agent, built on Llama-3.1-8B-Instruct and Qwen3-8B, and evaluate it on both static and adaptive prompt injection benchmarks. Experimental results show that SRFT substantially reduces attack success rates while preserving task per-formance, and demonstrates strong generalization under adaptive attacks. These findings suggest that learning from failure via self-reflection is a promising di-rection for building robust and secure LLM agents. Our code is released at 

https://github.com/Eden-Wang1710/srft-repo .

# 1 INTRODUCTION 

Recent advancements in AI agents have demonstrated the significant potential of large language models (LLMs) in autonomous systems. By leveraging external tools (Yao et al., 2023; Schick et al., 2023), LLM agents can interact with real-world environments and perform complex tasks across domains such as web navigation, computer use, and coding (Nakano et al., 2022; Deng et al., 2023; Zhou et al., 2024; Yang et al., 2024; Huang et al., 2024; Wang et al., 2025a; Xie et al., 2024; Wu et al., 2024). However, their reliance on external content makes LLM agents vulnerable to prompt injection attacks (Perez & Ribeiro, 2022; Wei et al., 2023). In these attacks, adversaries embed malicious instructions in external content that agents access, such as webpages. These instructions can divert the agent from the user’s original goal, a failure known as goal hijacking. Due to its severity, prompt injection has been ranked as the top risk in OWASP 2026 for agent applications. To mitigate this risk, prior work has explored both system-level and model-level defenses. System-level approaches aim to constrain agent behavior through carefully designed architectures and se-curity policies that prevent the execution of risky or unintended actions (Rebedea et al., 2023; Inan et al., 2023; Robey et al., 2024). In contrast, model-level approaches focus on enhancing the agent’s intrinsic ability to recognize and resist malicious instructions through safety alignment (Touvron et al., 2023; Jain et al., 2023; Hines et al., 2024). For example, StruQ (Chen et al., 2024) separates the input context into user queries and external data and supervised fine-tunes the model to prioritize user intent. SecAlign (Chen et al., 2025) uses Direct Preference Optimization (DPO) to train models to follow user instructions and ignore mali-cious instructions in external content. Recently, Meta SecAlign (Chen et al., 2026) further extends this paradigm by introducing explicit role separation between trusted and untrusted inputs within the model template, achieving state-of-the-art performance. Despite these advances, such approaches largely depend on pattern matching and tend to rigidly suppress external instructions, which may limit their flexibility. A fundamental limitation of existing methods is their reliance on static, expert-curated datasets, resulting in models that only imitate expert actions or learn pattern-based suppression. Although this paradigm provides an efficient way to instill defensive behaviors, it exposes the agent only to a limited set of predefined attack patterns. This limits the agent’s ability to generalize to novel or adaptive threats. In practice, prompt injection attacks can manifest in highly diverse forms, spanning different environments, tool-use trajectories, data formats, and goal-hijacking strategies, which static datasets fail to comprehensively capture. Moreover, because agents are trained passively without interacting with dynamic environments or receiving feedback from attack outcomes, they lack the ability to discover failure cases, correct unsafe behaviors, and improve through failure experience. Consequently, current approaches primarily enable agents to imitate known defensive patterns rather than develop a robust and generalizable understanding of how to resist goal hijacking in complex, real-world scenarios. Reinforcement learning offers a promising way to address these limitations, as it allows agents to collect diverse and out-of-distribution data by interacting with the environment. However, its application in agent settings remains challenging due to the high cost of environment construction and training, particularly for complex long-horizon agentic tasks. To address these challenges, we propose a novel Self-Reflection Fine-Tuning (SRFT) mechanism that enables the agent to learn from its failures in adversarial settings. As shown in Figure 1, instead of relying solely on static demonstrations, SRFT encourages the agent to learn from their failures by predicting and reasoning about potential consequences of its actions. Concretely, we first con-struct challenging training scenarios by injecting adversarial instructions into clean expert agentic trajectories. The agent is then rolled out in these contexts to expose failure cases where it follows the attacking instructions. Then an expert LLM compares the hijacked actions with the correspond-ing optimal ones and generates self-reflective rationales that explain why the optimal behaviors are preferable and what risks arise from executing the compromised actions. These reflections are sub-sequently used to fine-tune the agent, allowing it to internalize corrective signals derived from its own mistakes. Through this self-reflection learning paradigm, we develop SR-Agent , a series of models that exhibit strong robustness against both known and previously unseen adaptive prompt injection attacks. We evaluate our approach on two representative agent security benchmarks, InjecAgent (Zhan et al., 2024) and AgentDojo (Debenedetti et al., 2024). On AgentDojo, SRFT significantly reduces the at-tack success rate (ASR) from 7.59% to 1.26% on Llama-3.1-8B-Instruct and from 16.97% to 1.05% 2Preprint on Qwen3-8B, while maintaining competitive task utility. Furthermore, under a strong adaptive attack setting using RL-Hammer (Wen et al., 2025) on InjecAgent, which is designed to generate diverse and previously unseen attack strategies, SR-Agent consistently outperforms prior state-of-the-art methods. Notably, while Meta SecAlign exhibits an ASR exceeding 60% in this setting, SR-Agent obtains a final ASR below 20%. These results demonstrate the effectiveness of self-reflection as a training signal, enabling agents to generalize beyond static attack patterns and offering a prac-tical path toward more robust and deployable defenses. 

# 2 RELATED WORK 

Prompt Injection in Agentic Workflows. Prompt injection attacks exploit LLMs’ difficulty in dis-tinguishing trusted instructions from untrusted external content (Perez & Ribeiro, 2022; Wei et al., 2023). This risk increases in agentic workflows, where models repeatedly use tool responses to guide their next actions. Malicious instructions can be embedded within webpages, emails, docu-ments, retrieved content, or API responses (Greshake et al., 2023), causing agents to leak sensitive information, invoke unintended tools, or deviate from the original user objective (Kang et al., 2023). Existing benchmarks evaluate these risks at different levels. Some, such as InjecAgent, focus on relatively isolated settings and test whether models follow injected instructions in single-step sce-narios. In contrast, AgentDojo provides a dynamic, sandbox-style environment for evaluating end-to-end tool-using agents, where attacks are introduced through tool observations during multi-step execution. More recently, adaptive attack frameworks such as RL-Hammer and other automated red-teaming methods (Chao et al., 2024; Mehrotra et al., 2024) have further strengthened prompt injection attacks. These approaches train attacker models using reinforcement learning or iterative refinement to optimize attacks against specific targets. Such developments highlight the need to evaluate defenses not only against static attacks but also under realistic workflows and adaptively evolving adversaries. 

Defense against Prompt Injection. Existing defenses against prompt injection can be broadly categorized into system-level and model-level approaches. System-level defenses constrain agent behavior through mechanisms such as sandboxing, permission control, tool-use policies, informa-tion flow restrictions, and external monitoring (Rebedea et al., 2023; Inan et al., 2023; Robey et al., 2024; Debenedetti et al., 2025; Li et al., 2025; Shi et al., 2025; Wu et al., 2025). While effective in specific applications, these methods often require substantial engineering effort and may not gener-alize well across environments. Model-level defenses instead aim to improve the robustness of the LLM itself (Touvron et al., 2023; Jain et al., 2023; Hines et al., 2024). StruQ (Chen et al., 2024) introduces structured queries to explicitly separate trusted instructions from untrusted inputs and fine-tunes models to respect this boundary. SecAlign (Chen et al., 2025) formulates prompt injection defense as a preference optimization problem, encouraging models to favor secure responses over injection-following behaviors. Meta-SecAlign (Chen et al., 2026) further scales this approach and provides an open-source secure foundation model with strong security–utility trade-offs. Despite their effectiveness, these methods primarily rely on imitation of expert behaviors or pattern-based suppression, which may limit their ability to generalize to diverse and adaptive attack strategies. 

# 3 THREAT MODEL 

Attacker Goal. The attacker is usually a third-party entity. Their goal is to insert malicious instruc-tions into external resources (such as web pages or inbox messages) so that the agent is misled into following the attacker’s commands. 

Defender Goal. The defender’s goal is to prevent the agent from being hijacked by external in-structions while maintaining its ability to accomplish the original user task as much as possible. In indirect prompt injection scenarios, we do not assume the user to be the attacker. 

Attacker Capability. In our setting, the attacker’s capabilities should be realistic and feasible. Some prior work (Liu et al., 2025) assumes that the attacker can arbitrarily modify the external environment. Although this assumption is helpful for validating defenses, it overstates the attacker’s capabilities and cannot accurately reflect performance in real-world scenarios. We therefore assume that the attacker has access only to realistic attack surfaces. 3Preprint 

# 4 SRFT: S ELF -R EFLECTION FINE -T UNING 

4.1 OVERVIEW 

We propose SRFT, a self-reflection fine-tuning framework for improving the robustness of tool-integrated agents against prompt injection attacks. The framework consists of four stages. First, we synthesize executable prompt injection tasks with an expert LLM and insert them into clean expert trajectories. Second, we sample raw actions from the reference agent under the attacked context, collecting candidate actions that may include unsafe or sub-optimal behaviors. Third, we use a separate expert LLM to generate self-reflection thinking, which analyzes the original task, identifies the prompt injection, and reflects on why safe action is better than unsafe ones. Finally, we fine-tune the agent on the reflected thinking to let it learn from its failure experience. Overall, SRFT turns prompt injection defense from simple action imitation of traditional alignment into experience learning, which could broaden defense coverage and handle novel attacks. 4.2 STAGE I: P ROMPT INJECTION DATA SYNTHESIS 

We represent a complete agentic trajectory as a sequence of interleaved states s and actions a:

τ = ( s0, a 1, s 1, a 2, . . . , s n−1, a n).

Here, s0 represent the initial state, including the system prompt, tool definitions, user instructions, and any other initial context. ai denotes the i-th tool call, while si denotes the corresponding tool output. an represents the final assistant step, where the agent either informs the user that the opera-tional user goal has been completed, or provides the final answer based on the previously collected tool responses. In this trajectory, prompt injection may appear in any intermediate observation si.The goal of this stage is to transform clean expert trajectories into attacked training trajectories while preserving the original task objective. Starting from expert demonstrations without prompt injection, we use an expert LLM to synthesize executable injection tasks conditioned on the available tools: 

P = {pj }Kj=1 , pj ∼ G1(· | T ).

Here, T denotes the set of tool functions available in the current environment, and G1 represents a separate expert LLM prompted with Template 1 in Appendix B.1. The generated set P consists of injection tasks that are explicitly grounded in the available tools, ensuring that the injected objectives are executable within the agentic environment. Each synthesized injection task is further converted into a concrete prompt injection trigger using a predefined template: 

Ij = Qtrig (pj ), j = 1 , . . . , K, 

where Qtrig (·) denotes the trigger construction function. The resulting trigger Ij represents a ma-licious instruction that can be embedded into external observations. We provide prompt, trigger template and attack example in Appendix B.1. Given an intermediate observation si, we inject a trigger with probability equal to 0.5:

˜si = si ⊕ Ij ,

where ⊕ denotes insertion at a random position (e.g., beginning, middle, or end). This simulates diverse injection patterns and prevents the agent from exploiting positional biases. Importantly, the injected instruction does not alter the underlying task objective. Thus, the optimal expert action remains unchanged:

Given the sampled candidate actions, we construct self-reflection to enable the model to identify failure modes, allowing it not only to imitate the optimal action but also to understand why the optimal action is better than sub-optimal or hijacked ones. At each step i, conditioned on the trajectory prefix Hi, the optimal action ai, and the sampled action set Ai, we generate a self-reflection thinking sequence:

Given the generated self-reflection thinking, we can enforce the agent to learn from these failure experience, and train the agent to jointly produce safer and functional decision-making. At each step i, the training target consists of the thinking sequence Ci and optimal action ai, condi-tioned on the trajectory prefix Hi. We optimize the model using a standard supervised objective: 

L = − log Pθ (Ci, a i | Hi),

where θ denotes the parameters of the agent. This objective can be factorized as: 

L = − log Pθ (Ci | Hi) − log Pθ (ai | Hi, C i).

The factorization reflects a two-stage generation process in which the model first produces a self-reflection rationale and subsequently generates the final action conditioned on this reasoning. The first term promotes enhanced safety awareness under adversarial observations, while the second term enforces correct decision-making aligned with the original task objective. 5Preprint 

# 5 EXPERIMENT 

5.1 EXPERIMENTAL SETUPS 

Datasets. We use TOUCAN (Xu et al., 2025) as our base trajectory data, which collects 1.5M tool-agentic data from real-world MCP environments. We choose 5 platforms from TOUCAN: Hotel booking, Email sender, Windows Command Line, Markdown Downloader and Minecraft Wiki and filter 402 distinct user tasks with multiple tool callings to complete the task. We generate 38 malicious injection tasks in total. Combining them, the final training dataset consists of 3698 trajectories and 22339 assistant steps. We list the details of training data in Appendix B.1.1. In the prompt injection data synthesis stage, we use Claude Sonnet 4.6 as the expert model to gen-erate attacking samples and chain-of-thought think. For raw action sampling stage, we collect 3 responses for each assistant step. 

Implementation. Our main model, SR-Agent, fine-tunes Llama-3.1-8B-Instruct; we additionally train SR-Agent variants of Qwen3-8B and Qwen3-4B (Team, 2025) from the same data to test transfer across model families. All models use LoRA (Hu et al., 2021) with rank 64 and α = 96 

on the query, key, value and output projections of every layer (about 55M trainable parameters for Llama-3.1-8B), trained for 3 epochs with learning rate 5 × 10 −6, a cosine schedule with 10% warm-up, effective batch size 16, an 8k-token context and bfloat16 precision. 

Benchmarks. We evaluate SR-Agent on two representative agent security benchmarks: InjecA-gent (Zhan et al., 2024) and AgentDojo (Debenedetti et al., 2024). InjecAgent primarily evalu-ates isolated, single-step injection-following behavior. In contrast, AgentDojo is a sandbox-style benchmark designed for end-to-end evaluation of tool-using agents. It features four realistic agen-tic environments—Banking, Slack, Travel, and Workspace—comprising a total of 949 trajectories. Unlike earlier prompt injection benchmarks, AgentDojo evaluates the full agent execution process while malicious instructions may be dynamically introduced through tool-returned content, which provides a more comprehensive and realistic evaluation of an agent’s ability to preserve task utility while resisting prompt injection attacks in complex agentic workflows. In addition, we measure general capability on MMLU, MMLU-Pro, IFEval and BBH (Section 5.2). 

Metrics. We follow the evaluation settings of AgentDojo and InjecAgent, assessing performance from both functionality and security perspectives using three metrics: • Benign Utility : the agent’s ability to complete the original task in the absence of attacks. • Utility under Attack : the agent’s robustness in completing the user task under attack. • Attack Success Rate : the agent’s vulnerability to executing the attacker’s intended tasks. As shown in Table 4, SR-Agent pro-duces consistently shorter outputs than the base Qwen3-8B across both metrics. The mean number of thinking tokens decreases from 451.70 to 369.94, with the median reduced from 532.00 to 364.00. A similar trend is observed for total generated tokens. These results indicate that SRFT does not increase inference-time overhead. Instead, self-reflection supervision appears to encourage more concise and focused reasoning, leading to more efficient ac-tion generation. This demonstrates that SRFT is a practical and effective approach for real-world agent security systems. 

# 6 CONCLUSION 

In this paper, we introduce Self-Reflection Fine-Tuning (SRFT), a framework that improves the ro-bustness of LLM agents against prompt injection by enabling them to learn from failure experiences. SRFT explicitly exposes agents to adversarial scenarios and trains them to reason about the discrep-ancy between compromised and optimal actions. Through self-reflection reasoning, the agent learns not only what action to take, but why certain actions are unsafe and how they deviate from the orig-inal task objective. Empirical results across both standard and adaptive attack settings demonstrate that SRFT achieves strong robustness while maintaining practical task utility, highlighting the im-portance of experience-driven learning and explicit reasoning in agent security. # A ADDITIONAL R ELATED WORK 

A.1 LLM A GENTS 

LLM agents extend language models from passive text generators into interactive systems capa-ble of planning, tool use, and multi-step decision-making. Early works such as ReAct (Yao et al., 2023) and Toolformer (Schick et al., 2023) demonstrate that language models can interleave rea-soning with actions to solve complex tasks. More recent systems further expand these capabilities by integrating LLMs with diverse external environments, including web browsers (Nakano et al., 2022; Deng et al., 2023; Zhou et al., 2024), code interpreters (Yang et al., 2024; Huang et al., 2024; Wang et al., 2025a), third-party APIs (Qin et al., 2023), and operating systems (Xie et al., 2024; Wu et al., 2024). Recent studies have also explored strengthening LLM agents through supervised fine-tuning or reinforcement learning on agentic trajectories, improving their tool-use and decision-making capabilities from demonstrations or environment feedback (Zhang et al., 2025; Wang et al., 2025b). A.2 PROMPT INJECTION IN AGENTIC WORKFLOWS 

Prompt injection attacks exploit the inability of LLMs to reliably distinguish between trusted instruc-tions and untrusted external content (Perez & Ribeiro, 2022; Wei et al., 2023). This vulnerability is amplified in agentic workflows, where models repeatedly observe tool outputs and use them to guide future actions. Malicious instructions can be embedded within webpages, emails, documents, retrieved content, or API responses (Greshake et al., 2023), causing agents to leak sensitive infor-mation, invoke unintended tools, or deviate from the original user objective (Kang et al., 2023). Existing benchmarks evaluate these risks at different levels. 

Static Attacks and Evaluation Benchmarks. InjecAgent evaluates whether models follow injected instructions in relatively isolated, single-step settings. In contrast, AgentDojo provides a dynamic, sandbox-style environment where agents use diverse tools to complete multi-step user tasks. It eval-uates complete agentic trajectories, with attacks introduced through tool outputs during execution. This setup more closely reflects real-world agent workflows and measures both security and task utility: whether agents resist prompt injection and successfully complete the user’s original task. 

Adaptive Attacks and Automated Red-Teaming. Automated red-teaming methods such as PAIR and TAP iteratively refine jailbreak prompts using feedback from target models (Chao et al., 2024; Mehrotra et al., 2024). RL-Hammer (Wen et al., 2025) trains an attacker model with reinforcement learning to generate prompt injections. Specifically, it uses Group Relative Policy Optimization 13 Preprint (GRPO) to rewrite injection instructions, with rewards based on the target model’s responses. Its training recipe removes KL regularization and combines feedback from the defended target and a weaker model. The weaker model provides additional learning signals when successful attacks against the defended target are rare. Such developments highlight the need to evaluate defenses not only against static attacks but also under realistic workflows and adaptively evolving adversaries. A.3 DEFENSE AGAINST PROMPT INJECTION 

Existing defenses against prompt injection can be broadly categorized into system-level and model-level approaches. 

System-level Defenses. System-level defenses constrain agent behavior through mechanisms such as sandboxing, permission control, tool-use policies, information flow restrictions, and external monitoring (Rebedea et al., 2023; Inan et al., 2023; Robey et al., 2024; Debenedetti et al., 2025; Li et al., 2025; Shi et al., 2025; Wu et al., 2025). While effective in specific applications, these methods often require substantial engineering effort and may not generalize well across environments. 

Model-level Defenses. Model-level defenses instead aim to improve the robustness of the LLM it-self (Touvron et al., 2023; Jain et al., 2023; Hines et al., 2024). StruQ (Chen et al., 2024) introduces structured queries to explicitly separate trusted instructions from untrusted inputs and fine-tunes models to respect this boundary. SecAlign (Chen et al., 2025) formulates prompt injection defense as a preference optimization problem, encouraging models to favor secure responses over injection-following behaviors. Meta-SecAlign (Chen et al., 2026) further scales this approach and provides an open-source secure foundation model with strong security–utility trade-offs. All three construct their main defensive training datasets from Cleaned Alpaca, a general-purpose instruction-tuning dataset, by adding synthetic prompt injections. ReasAlign (Li et al., 2026b) introduces structured reasoning into defensive training. Despite their effectiveness, these methods primarily rely on imitation of expert behaviors or pattern-based suppression, which may limit their ability to generalize to diverse and adaptive attack strategies. Also, these instruction-following and question-answering examples do not explicitly model multi-step tool interactions or the evolving context of an agentic trajectory. In contrast, SRFT constructs reflective supervision within multi-step tool-use trajectories, compar-ing agent-sampled actions with expert actions and analyzing their potential consequences. This experience-driven learning paradigm enables the model to capture underlying reasoning patterns and improves robustness to unseen attacks.
