## 摘要
大语言模型（LLM）智能体的防御通常是逐会话进行评估的。然而在实际部署中，攻击可能分布在独立的智能体、团队和运行时之间，导致每个局部护栏（guardrail）仅能获取到稀疏的攻击片段。我们形式化了跨智能体异步攻击活动归因：在没有共享运行时状态、测试时攻击活动标签或攻击者身份先验（oracles）的情况下，关联来自同一潜在对抗性攻击活动的会话。我们引入了异步归因指纹向量（$A^2FV$），这是一种轻量级的代理端参考协议，用于根据代理可观测的工具使用、时序和提示词残留来评估成对攻击活动的相似性。我们还构建了 SCD-v1，这是一个受控的人格匹配基准，包含良性流量、孤立攻击、多会话攻击活动、匹配的非先验规避以及泄露审计。在 SCD-v1 上，$A^2FV$ 在攻击活动关联方面实现了 0.82 的成对 AUC，而仅基于评分的逐会话检测器适配版和分块 LLM 评判员在相同任务下的表现仍接近随机水平。最强的固定信号由结构和文体残留承载，而时序则作为诊断通道保留，用于更丰富的代理追踪。交叉风格对照实验表明，该信号在一定程度上对风格敏感，但不能仅归结为风格。静态和维度感知的非先验压力测试进一步表明，在受控规避下，成对可分性依然存在。这些结果确立了跨智能体攻击活动归因是保障真实环境下 LLM 智能体安全的一个独立评估层。

## Abstract
LLM-agent defenses are typically evaluated one session at a time. In deployment, however, attacks can be distributed across independent agents, teams, and runtimes, leaving each local guardrail with only a sparse fragment. We formalize cross-agent asynchronous campaign attribution: linking sessions from the same latent adversarial campaign without shared runtime state, test-time campaign labels, or attacker identity oracles. We introduce Asynchronous Attribution Fingerprint Vectors ($A^2FV$), a lightweight proxy-side reference protocol for scoring pairwise campaign similarity from proxy-observable tool-use, timing, and prompt residue. We also construct SCD-v1, a controlled persona-matched benchmark with benign traffic, isolated attacks, multi-session campaigns, matched non-oracle evasion, and leakage audits. On SCD-v1, $A^2FV$ achieves 0.82 pairwise AUC for campaign linking, while score-only adaptations of per-session detectors and chunked LLM judges remain near chance under the same task. The strongest fixed signal is carried by structural and stylometric residue, while timing is retained as a diagnostic channel for richer proxy traces. Crossed-style controls show that the signal is partly style-sensitive but not reducible to style alone. Static and dimension-aware non-oracle stress tests further show that pairwise separability persists under controlled evasion. These results establish cross-agent campaign attribution as a distinct evaluation layer for securing LLM agents in the wild.

## 论文详细总结（自动生成）

这篇论文由 Tynapse 团队发表于 ICML 2026 的 AIWILD 研讨会，探讨了 LLM 智能体安全领域一个被忽视的维度：如何关联分布在不同时间、不同智能体上的碎片化攻击。

### 1. 核心问题与整体含义（研究动机和背景）
*   **研究动机**：目前的 LLM 智能体防御（如护栏、注入检测）大多是“逐会话”进行的。然而，攻击者可以发起**分布式异步攻击活动（Campaign）**，将攻击载荷拆分并投放到不同的智能体（如财务、客服、代码助手）中。
*   **核心问题**：由于各智能体之间往往没有共享的内存或运行时状态，局部防御只能看到孤立的、看似无害的片段。论文旨在解决如何在共享代理（Proxy）层，仅通过可观测的遥测数据（提示词、工具调用、时间戳），将属于同一攻击者的多个会话关联起来。

### 2. 核心方法论：$A^2FV$ 协议
论文提出了**异步归因指纹向量（Asynchronous Attribution Fingerprint Vectors, $A^2FV$）**，这是一种轻量级的代理端关联协议。其核心思想是提取三个维度的“残留信号”：
*   **结构残留（Structural Residue）**：分析工具调用的“骨架”。提取工具名称与执行结果（成功/失败）的 n-gram 特征，以及基于 MITRE ATT&CK 框架的战术直方图。
*   **文体残留（Stylometric Residue）**：捕捉提示词的表面特征而非语义。利用字符级和字节级的 n-gram（TF-IDF 向量化）来识别攻击者的书写习惯、标点偏好或特定短语。
*   **时序残留（Temporal Residue）**：记录工具调用之间的时间间隔（Gaps）和载荷大小。虽然在当前实验中信号较弱，但被保留作为识别自动化脚本或特定网络抖动的诊断通道。
*   **算法流程**：
    1.  代理层收集各会话的遥测数据。
    2.  将数据转化为上述三个维度的特征向量并进行归一化。
    3.  计算成对会话间的加权余弦相似度得分。
    4.  利用 HDBSCAN 等聚类算法对高相似度会话进行分组，从而识别潜在的攻击活动。

### 3. 实验设计
*   **数据集/场景**：构建了 **SCD-v1** 基准测试。包含 70% 良性流量、15% 孤立攻击和 15% 多会话攻击活动。涵盖 40 种攻击者人格（Persona），并设计了 L0（无规避）到 L2（多维度静态规避）的对抗场景。
*   **对比方法**：
    *   **逐会话检测器适配版**：如 PromptShield、DataSentinel，通过比较其安全评分的差异来尝试关联。
    *   **LLM 评判员（LLM Judges）**：使用 GPT-5.5、Claude 4.7 等模型对会话进行分块聚类。
    *   **MAScope-async**：一种针对同步多智能体系统的防御方法的异步适配版。
*   **评估指标**：主要使用成对 AUC（Pairwise AUC）来衡量关联准确性，辅以 V-measure 评估聚类质量。

### 4. 资源与算力

### 5. 实验数量与充分性
*   **实验规模**：主基准测试包含 2000 个会话。
*   **充分性验证**：
    *   **消融实验**：分别测试了结构、文体、时序特征的独立贡献。
    *   **跨模型验证**：在 Qwen-3.6、Gemini-3.1 Pro 等不同生成器上进行了再生验证。
    *   **原生框架探测**：在 OpenClaw 和 LangGraph 等真实智能体框架上进行了压力测试。
    *   **规避测试**：模拟了攻击者通过改写提示词、加入随机延迟等手段进行规避时的表现。
*   **评价**：实验设计较为全面，通过交叉风格控制和泄露审计（Leakage Audits）确保了结果的客观性，证明了信号并非来自简单的标签泄露。

### 6. 主要结论与发现
*   **$A^2FV$ 表现优异**：在 SCD-v1 上实现了 **0.82 的成对 AUC**，远超基于评分的检测器（约 0.52）和 LLM 评判员（约 0.51）。
*   **结构与文体是关键**：工具调用的结构和提示词的文体残留提供了最强的关联信号。
*   **静态规避难以完全抹除指纹**：即使攻击者尝试改写或加入干扰，只要攻击载荷的功能需求不变，其工具使用模式和残留风格仍具有可辨识性。
*   **LLM 评判员的局限**：在大规模会话中，由于上下文窗口限制，LLM 难以维持全局的身份一致性，导致关联失败。

### 7. 优点
*   **新颖的视角**：首次形式化了“跨智能体异步攻击活动归因”这一安全层，填补了单会话防御的空白。
*   **轻量且透明**：$A^2FV$ 不需要复杂的模型训练，易于在现有的 API 网关或代理层部署。
*   **防御深度**：通过多维度特征（结构+文体+时序）构建了防御纵深，增加了攻击者的规避成本。

### 8. 不足与局限
*   **合成数据偏差**：SCD-v1 虽经过精心设计，但仍是合成数据，真实生产环境中的良性噪声可能更复杂。
*   **风格敏感性**：实验发现信号部分依赖于文体风格，如果攻击者能够完美进行风格转换（Style Transfer），关联效果可能会下降。
*   **缺乏完全自适应攻击测试**：论文主要测试了静态规避，尚未深入探讨攻击者在获得防御方评分反馈（Oracle access）后的完全自适应攻击表现。
*   **隐私风险**：文体指纹可能无意中泄露合法用户的个人写作习惯，部署时需考虑隐私保护和合规性。
