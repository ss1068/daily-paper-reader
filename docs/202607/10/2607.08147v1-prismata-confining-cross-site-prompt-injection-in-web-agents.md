## 摘要
自主 Web 智能体有望实现日常浏览任务的自动化，但同时也继承了 Web 最古老的攻击面之一。跨站脚本攻击（XSS）证明了即使在良性页面上，混合受信任和不受信任的内容也是危险的。智能体通过将自然语言解释为指令，使这一风险再次浮现，从而允许第三方和用户生成的内容通过提示词注入（prompt injection）劫持智能体。核心挑战在于，推导特定任务的安全策略需要对与攻击者内容纠缠在一起的页面结构进行推理。我们提出了 Prismata，这是一种为 Web 智能体强制执行上下文最小特权（contextual least privilege）的防御机制，它同时限制了智能体可见的内容及其可执行的操作。Prismata 的动态信任推导为页面内容生成权限标签，并受经典完整性模型的启发，提供结构性限制保证，从而界定任何标签错误，使得标签只能降低特权级别，且误标情况是有界的。Prismata 的机械限制通过脱敏内容和限制智能体能力来强制执行这些标签。重要的是，这些机制不需要开发人员进行标注，因此 Prismata 支持长尾网站。在近期发布的 Web 智能体攻击（包括自适应变体）中，Prismata 在保持良性任务效用的同时，显著降低了攻击成功率。

## Abstract
Autonomous web agents promise to automate everyday browsing tasks, but inherit one of the web's oldest attack surfaces. Cross-Site Scripting proved that mixing trusted and untrusted content is dangerous, even on benign pages. Agents resurface this risk by interpreting natural language as instructions, allowing third-party and user-generated content to hijack the agent via prompt injection. The core challenge is that deriving a task-specific security policy requires reasoning over page structure that is entangled with the attacker's content.   We present Prismata, a defense enforcing contextual least privilege for web agents, constraining both what the agent sees and what it can do. Prismata's dynamic trust derivation produces permission labels for page content, with structural confinement guarantees, inspired by classical integrity models, that bound any labeling errors so that labels can only decrease in privilege and mislabelings are bounded. Prismata's mechanical confinement enforces these labels by redacting content and restricting agent capabilities. Importantly, these mechanisms require no developer annotations, so Prismata supports the long tail of websites. Across recent published web agent attacks, including adaptive variants, Prismata substantially reduces attack success while preserving benign task utility.

### 1. 核心问题与整体含义
*   **研究动机**：自主 Web 智能体在执行任务（如购物、订票）时，需要解析网页内容。然而，网页通常混合了开发者内容（受信任）和用户生成内容/广告（不受信任）。
*   **核心威胁**：攻击者可以在评论区或广告中嵌入恶意指令（即 XSP，类似于 Web 安全中的 XSS），诱导智能体执行越权操作（如泄露信用卡信息、重置密码）。
*   **挑战（Web 纠缠问题）**：要判断一个操作是否安全，必须理解页面结构，但页面结构往往与攻击者控制的内容交织在一起。现有的防御手段要么依赖模型自身的鲁棒性（易被绕过），要么需要开发者手动标注页面（难以扩展）。

### 2. 方法论
Prismata 的核心思想是为 Web 智能体强制执行**上下文最小特权（Contextual Least Privilege）**，即只让智能体看到并操作完成任务所必需的内容。

*   **动态信任推导（Dynamic Trust Derivation）**：
    *   **动作门控（Action Gate）**：针对页面上的每个交互元素，提取其从根节点到该元素的“关键路径”（Critical Path）。模型仅根据路径上的结构信息和用户任务来判断该元素是否在范围内，从而隔离了路径之外的攻击内容。
    *   **Biba 解析（Biba Parsing）**：受 1977 年 Biba 完整性模型启发，采用“不向下读、不向上写”原则。递归评估 DOM 路径，利用标题（如“评论”）、ARIA 标签等结构化线索，在接触到具体内容前识别出不受信任的边界。
*   **机械化限制（Mechanical Confinement）**：
    *   这是一个确定性的执行层。根据推导出的标签，Prismata 会在观察结果传递给智能体之前，直接从可访问性树（AxTree）中删除无关内容，或将敏感操作（如重置密码）降级为只读状态。
*   **无需标注**：该方法完全基于现有的 HTML 结构和语义线索，不需要网站开发者进行任何额外配置。

*   **实验规模**：
    *   对 **1,500 多个**顶级网站的 **90,000 多条**路径进行了实证分析，验证了“关键路径”假设的普遍性。

### 6. 主要结论与发现
*   **防御有效性**：Prismata 将攻击成功率（ASR）从 **85.5% 降低至 0.7%**。
*   **任务效用**：在遭受攻击的情况下，任务成功率（TSR）从 4.5% 提升至 23.0%；在无攻击的正常场景下，TSR 仅从 29.9% 轻微下降至 26.6%，证明了其**低副作用**。
*   **结构化线索**：实证发现 98.8% 的不受信任内容并不在通往交互元素的关键路径上，这为 Prismata 的有效性提供了理论支撑。

### 7. 优点
*   **系统级防御**：不依赖于 LLM 自身的“道德对齐”，而是通过系统架构强制执行安全策略。
*   **零成本部署**：兼容现有的长尾网站，无需网站管理员修改代码。
*   **理论扎实**：将经典的计算机安全模型（Biba）成功应用于现代 AI 智能体领域。
*   **性能优化**：通过多层缓存机制解决了 DOM 解析带来的高延迟和高成本问题。

### 8. 不足与局限
*   **模态限制**：目前仅支持文本模态，无法防御基于图像扰动（对抗攻击）的多模态注入。
*   **结构依赖**：如果网站完全缺乏语义结构（如所有标签都使用无意义的 `div` 且无类名），防御效果可能会打折扣。
*   **残留风险**：在极少数情况下（约 0.1%），攻击内容可能直接出现在关键路径上且缺乏前置线索，此时仍存在被绕过的风险。
*   **延迟开销**：尽管有缓存，但在首次访问新页面时，多层次的 LLM 评估仍会增加一定的响应延迟。
