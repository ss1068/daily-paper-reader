## 摘要
自我改进智能体运行时的安全性声明几乎总是“自评式”的：例如一个策略文件、一个护栏或 README 中的承诺。我们描述了可证伪的发布门禁，以及一种构建和验证此类系统的方法论，使得每一项新功能在发布前都必须通过预先指定的、机器可验证的验收测试套件，并且在每个门禁处都保持一组固定的常驻不变性。我们在开源运行时 Antahkarana 中应用了该方法，通过七个门禁实现了从基础可观测性到能够建议自身策略更改的自治循环。任何动作在到达执行器之前，必须持有由控制环（control ring）铸造的安全关键属性能力令牌；该令牌在有界模型的 100 万个记录的可达状态空间中经过详尽的机器检查，并根据执行轨迹进行复核。一个故意破坏的模型会给出最短的反例，从而证明了检查器的有效性。自我增强循环受到正向约束：整个写入面均为策略规则，收紧性更改可自动应用，而放宽性更改始终需要人工合并，且预测自身效果错误的提案会被自动关闭。我们发布了所有七个门禁的验收测量结果，精确定义了每项声明的范围（协调骨架的有界范围，而非学习组件），并开源了运行时（包括命令行工具和门禁套件），以确保结果可复现，且门禁可针对其他智能体框架运行。审稿人可以在几秒钟内通过单条命令重复核心的不可逾越性验证。

## Abstract

We describe falsifiable release gates, and a methodology to build and validate such systems, such that every new capability must pass a pre-specified, machine-verifiable acceptance suite before it ships, and a fixed set of standing invariants is preserved at each gate.
